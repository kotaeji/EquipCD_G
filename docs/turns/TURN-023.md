# TURN-023 흐름 편집 다듬기 — 블록 이름 · 블록 옮기기 · 겹친 흐름 표

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.3.0`. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

- 분기 · 병렬 · 반복 · 재시도 행에 이름 입력 칸을 두었다. `aria-label` 은 「분기 이름」처럼 종류 낱말 + 이름이다. 빈 이름은 `이름 필요` 로 거절하고 칸은 원래 이름으로 돌아간다. 실행 중 · 일시정지 중에는 칸이 잠긴다. 바꾸기는 실행 취소 한 번이다.
- 블록 제목은 `flowBlockTitle` 한 곳이다. 흐름 표와 SFC 가 같이 쓴다. 이름이 종류 낱말과 같으면 「분기」처럼 한 번만, 다르면 「분기 검사 결과」처럼 종류 + 이름이다.
- 블록 행과 Substation 단계 행에도 선택 칸, 위로 · 아래로 · 밖으로, ↑↓ 키가 있다. 블록은 안의 단계 · 조건 · 횟수 · 갈래와 함께 옮겨진다. 맨 앞 · 맨 바깥처럼 옮길 수 없으면 지금 문구(`이동 불가`, `이미 맨 바깥입니다`)가 나온다.
- 고른 블록 · Substation 단계를 갈래의 「선택 넣기」로 넣을 수 있다. 자기 자신 안은 `블록을 자기 자신 안에 넣을 수 없습니다`. 병렬 갈래 안의 병렬 · Substation 단계는 `병렬 갈래 안에는 병렬과 Substation 단계를 넣지 않습니다`.
- 같은 갈래에서 연속이면 단계와 블록 · Substation 단계가 섞여 있어도 분기 · 병렬 · 반복 · 재시도로 묶인다. 연속이 아니면 `같은 갈래에서 연속된 단계만 묶을 수 있습니다`. 병렬로 묶을 때도 병렬 갈래 규칙을 적용한다.
- Station 시퀀스 화면의 흐름 표와 묶기 단추 줄은 `FlowEditor` 한 번이다. 접는 칸은 단계 편집과 구조화 문장 입력만 남겼다.

## 화면 (1280×800, 흐름 예제)

Chrome 으로 개발 서버를 열어 찍었다. 분기 이름을 「검사 결과」로 바꾼 뒤다. 제목은 흐름 표와 SFC 모두 「분기 검사 결과」다.

- 흐름 표, 라이트: `TURN-023-flow-light-1280.png`
- 흐름 표, 다크: `TURN-023-flow-dark-1280.png`
- SFC, 라이트: `TURN-023-sfc-light-1280.png`
- SFC, 다크: `TURN-023-sfc-dark-1280.png`

같은 화면에서 빈 이름은 거절되고 칸이 「읽기 결과」로 돌아왔다. 재시도 블록을 아래로 옮기면 다음 형제인 분기 뒤로 가고, 안의 단계는 블록과 같이 움직였다. 위로 한 번에 원래 자리로 돌아왔다. `aria-label="Station 흐름"` 표와 묶기 단추 네 개는 하나씩이었다.

## 확인 필요

- 이름이 종류 낱말과 다르면 제목은 항상 종류 + 이름이다. 흐름 예제의 재시도는 「재시도 읽기 재시도」로 보인다.
- 접는 칸의 `SequencePanel` 은 흐름 표를 더 이상 그리지 않는다. 이 화면 밖에서는 그 표를 쓰지 않았다.
- 로컬 `npm run typecheck` 와 `npm test` (36파일 490개) 는 통과했다. CI 판정은 이 기록이 아니다.
