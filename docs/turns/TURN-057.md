# TURN-057 내 템플릿 저장 · 다시 쓰기

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 프로젝트 파일 형식은 `0.3.0` 그대로다. `release/` 는 다시 빌드하지 않았다. `README.md` 는 이 PR에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 바뀐 조작

1. 2단계에서 Unit 하나를 고르고 도구 줄 또는 우클릭 메뉴의 「내 템플릿으로 저장」을 누른다. 이름은 기본이 Unit 이름이다. 같은 이름이 있으면 덮어쓸지 새 이름으로 할지 묻는다.
2. 들어가는 것은 복사 · 붙여넣기와 같은 추출이다. Unit 속성, 안의 Device · 신호 · 포지션 · Action, 안쪽 연결만 저장한다. 바깥 연결 · 시퀀스 단계 · 자재 경로 · Interlock 은 빠지고, 저장할 때 「빠짐: …」이 나온다.
3. 저장 위치는 이 브라우저의 `ecd.v1.templates` 와 `ecd.v1.templates.<id>` 다. 프로젝트 rev · Undo · 프로젝트 파일은 바뀌지 않는다. 저장소를 쓸 수 없으면 단추가 흐리고 까닭이 적힌다.
4. 팔레트와 1단계 라이브러리에 「내 템플릿」 묶음이 생긴다. 끌어 놓거나 「프로젝트에 추가」하면 새 ID 의 Unit 이 생긴다. 이름은 비어 있으면 그대로, 겹치면 「이름 2」다. 한 번 놓기는 rev +1 · Undo 한 번이고 실행 중에는 막힌다.
5. 놓은 Unit 의 근거는 「내 템플릿 〈이름〉에서」다. 템플릿을 고치거나 지워도 이미 놓은 Unit 은 그대로다. 삭제는 확인 창을 거치고 처음 초점은 취소다.
6. 템플릿 하나는 JSON 으로 내보내고 가져온다. 형식 이름은 `aurora-concept-designer/unit-template`, 버전은 `0.1.0` 이다. 깨진 파일은 거부한다. 저장 항목이 깨져 있으면 그 항목만 빼고 나머지를 보여 준다.

## 한 일

- 추출은 `captureCopy` 를 그대로 쓰고, 놓기는 붙여넣기 함수에 이름 · 위치 · 근거 선택만 더했다.
- 저장소는 프로젝트 트랜잭션 키가 아니다. 프로젝트 파일 형식 버전은 올리지 않았다. `lineage.fromTemplate` 은 없어도 되는 칸이라 예전 파일은 그대로 열린다.
- 새 CSS 는 `src/ui/user-templates.css` 다. `styles.css` 에는 더하지 않았다.
- 로컬에서 `npm test` 가 통과했다. 통과 판정은 CI 다.

## 확인 필요

- AC14 는 Matthew 검수 전이다. 이 문서는 완료로 적지 않는다.
- 같은 프로젝트에 놓으면, 템플릿 안 Action 이 가리키는 바깥 Unit 이 아직 있으면 그 참조는 붙여넣기와 같이 남는다. 연결선 자체는 템플릿에 없으므로 다시 생기지 않는다. 그 Unit 이 없는 프로젝트에서는 이동 대상을 뺀다.
- 템플릿 이름 비교는 앞뒤 공백을 지운 뒤 대소를 가리지 않는다. 놓은 Unit 의 근거 이름은 놓은 시점의 이름이다.
