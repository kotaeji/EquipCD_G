상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.3.1`. `release/` 는 다시 빌드하지 않았다. `README.md` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

진행 중 · 완료 · 오류 · 대기 · 미정 · 가정 여섯 상태를 `src/ui/status.ts` 한 파일에 모았다. 각 상태는 낱말, 기호, 라이트·다크 색을 갖는다. 화면은 `StatusMark` 로 그 정의를 그린다. 기호만 두거나 색만 두지 않는다.

| 상태 | 낱말 | 기호 | 색 변수 | 라이트 | 다크 | 쓰는 화면 |
|---|---|---|---|---|---|---|
| 진행 중 | 진행 중 | ▶ | `--status-active` | `#1a1a1a` | `#42d6cc` | 단계 줄, 흐름 표, 요약 표, SFC, 도면, 3D, 트리 |
| 완료 | 완료 | ✓ | `--status-done` | `#176642` | `#88dfb1` | 위와 같음 |
| 오류 | 오류 | ! | `--status-error` | `#b42336` | `#ff9fab` | 위와 같음 |
| 대기 | 대기 | ○ | `--status-pending` | `#5c5c5c` | `#b3c4d9` | 위와 같음 |
| 미정 | 미정 | ? | `--status-undetermined` | `#1a4f8b` | `#b9d4ff` | 3단계 속성 · Action, 5단계 Gap, Export, 남은 항목 |
| 가정 | 가정 | △ | `--status-assumption` | `#8b4800` | `#ffd18a` | 위와 같음. 실행 전 단계 줄도 가정 |

실행 단계와의 대응. `pending` → 대기, `active` → 진행 중, `done` → 완료, `error` → 오류. 낱말은 `stepStatusLabel` 그대로다.

| 실행 단계 | 낱말 | 쓰는 모양 |
|---|---|---|
| pending | 대기 | 대기 |
| active | 진행 중 | 진행 중 |
| done | 완료 | 완료 |
| error | 오류 | 오류 |
| skipped | 건너뜀 | 대기 (○, `--status-pending`) |
| stopped | 정지 | 가정 (△, `--status-assumption`) |

Station 실행 상태 낱말은 바꾸지 않았다. 실행 중은 진행 중 모양, 일시정지는 대기 모양이다. 그룹 정지는 낱말을 유지하고 가정 모양을 쓴다.

진행 중 줄 강조(옅은 바탕 `--selected`, 2px `--accent` 테두리, 굵은 글자)는 그대로다. 글자색은 상태 색이고, 대비는 라이트·다크 모두 글자 4.5:1, 기호와 테두리 3:1 이상이다. 바탕은 panel · canvas · selected · bg 다.

## 낱말을 맞춘 곳

| 전 | 후 | 어디 |
|---|---|---|
| ▼ 동작 중 | ▶ 진행 중 | 도면 실행 표시, 3D 표식 |
| 동작 중 | 진행 중 | 6단계 선택한 Device |
| 미정/비교 불가 | 미정 | Gap 판정 |
| 가정 포함 | 가정 | Export 상태 칸 |
| 가정값 존재 | 가정 | 남은 항목 배지 |
| 완료 미정 | 미정 | Action 능력 표 |
| 미정/누락 | 미정 | 정의 체크 |
| 미정(개념 신호) | 미정, 옆에 「개념 신호」 | 신호 주소 |
| (가정) · 가정값 | 가정 | 수량 칸 |

판정 규칙은 바꾸지 않았다. 필수 충족 · 필수 누락 · 재확인 필요 · 확인됨, 그리고 대기 · 실행 중 · 일시정지 · 완료 · 오류(`runStatusLabel`)도 바꾸지 않았다.

단계 바 배지의 기호는 색과 같은 상태에서 온다. 필수 충족 · 확인됨은 완료(✓), 필수 누락은 오류(!), 재확인 필요는 미정(?)이다. `WIZARD_BADGE_STATUS` 가 상태를 정하고 `BADGE_MARK` 는 그 상태의 기호를 쓴다.

탐색기 트리는 자리가 좁아 기호만 보인다. 낱말은 `aria-label` 과 `title` 에 있고, 칩 너비는 22px 를 넘지 않는다. Device 이름과 종류는 그 옆에 남는다.
