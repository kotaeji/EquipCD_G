# TURN-086 3D 보기 품질 — 정한 시점 · 바닥 격자 · 그림자 · 고른 것 윤곽

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `release/` 는 다시 빌드하지 않았다. `README.md` 는 이 TURN 에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

- 3D 장면 위에 시점 단추 등각 · 위 · 앞 · 옆을 두었다. 키보드 1~4도 같은 시점이다. 옮기는 시간은 `--dur-3`(320ms)이고, 「움직임 줄이기」면 한 번에 도착한다. 「전체 보기」와 Home 은 지금처럼 등각으로 맞춘다.
- 시점 줄은 단추 높이 28px 가 들어가게 두고, 장면은 그 아래에서 시작한다. 1280×800 에서 단추 아래쪽이 캔버스에 가리지 않고, 문서 스크롤은 0 이다.
- 「위」는 도면과 같은 방향이다. yaw 0, pitch 1.5(거의 수직, 바로 위는 아님 — 시선 축이 무너지지 않게).
- 구석의 방향 표시는 카메라 yaw 를 따라 돈다. 앞 · 뒤 · 좌 · 우를 누르면 그 방향으로 간다. 위쪽에 온 글자가 지금 보는 쪽이다.
- 바닥 격자는 도면 점 간격과 같은 20mm 다. mm 숫자는 가까운 두 변에만 둔다. 「가동 조건」의 「바닥 격자」로 끄고, 켜짐은 UserView 에 남는다. 시점 id 도 같이 남는다. 프로젝트 파일에는 쓰지 않는다.
- 장치 아래 그림자는 평면에 한 장으로 그린다. 실시간 그림자 맵은 켜지 않는다. 도식과 실사풍 둘 다 같은 접지 그림자를 쓴다.
- 고른 Device 는 굵기 6mm 윤곽과 이름표 굵은 테두리(`is-selected`)로 표시한다. 고른 Unit 은 바닥 구역 테두리를 4mm 에서 9mm 로 굵히고 초점색을 쓴다.
- 먼 곳은 캔버스 색으로 옅어진다. 라이트와 다크가 각자 배경색을 쓴다.
- WebGL 이 없으면 예전 문구와 「도면으로 보기」가 그대로다. 모델과 실행 규칙은 바꾸지 않았다.

## 프레임 시간 (AC7)

장치 60개, 장치마다 부품 6개. 품질을 켠 쪽은 접지 그림자 1장, 격자 1개, 윤곽 1개를 더한다. 행렬 갱신 80회 중 한 프레임의 중앙값(7회 중 4번째)이다. 로컬 `tests/turn086.test.ts` 결과: 바꾸기 전 0.018ms, 바꾼 뒤 0.018ms, 비 0.998. 같은 검사를 앞서 두 번 돌렸을 때는 0.959 와 1.025 였다. 1.20 을 넘지 않았다. 그림자 맵은 꺼 둔 상태라 실사풍의 예전 그림자 맵 패스는 없다.

## 하지 않은 것

- 실시간 그림자 맵, 재질 고급화, 장치 모델 교체, VR, 장면 내보내기
- `README.md`, `release/` 재빌드, 의존성 추가, `tests/turn054.test.ts`
- 모델 · 실행 규칙, 이름표 규칙(TURN-054)

## 확인 필요

- 접지 그림자는 부드러운 얼룩이 아니라 장치 발 밑의 반투명 평면이다. 도식에서는 실사풍보다 옅게 보인다.
- 「전체 보기」는 이번 장면만 등각으로 맞추고, 기억된 시점 id 는 지우지 않는다. 다음에 3D 를 열면 마지막 시점 단추가 다시 적용된다.
- 검토에서 잘리던 시점 단추는 줄을 높여 고쳤다. 「위」는 yaw 0 · pitch 1.5 로 바꿨다.
- 옆 · 왼쪽 시점은 등각 맞춤 루프가 거리를 너무 밀어 장면이 작아져서, 같은 바라보는 점을 유지한 채 거리만 다시 맞춘다.
