# TURN-051 문제 안내 세 줄 형식 · 빈 화면과 준비 중 화면

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.5.0`. `release/` 는 다시 빌드하지 않았다. `README.md` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

막힘과 빈 화면의 문구를 `src/ui/problemCopy.ts` 한 파일에 모았다. 화면은 `Problem` 과 `EmptyState` 를 쓴다.

문제 안내는 세 줄이다. **무엇**은 굵은 한 줄이고, **왜**와 **어떻게**가 그 아래 있다. 상태 기호와 색은 TURN-039 의 오류 · 미정 · 가정이다. 갈 곳이 있으면 이동 단추가 있고, 누르면 TURN-038 과 같이 그 칸을 약 2초 강조한다. 갈 곳이 없으면 단추를 두지 않는다. 고칠 방법을 알 수 없는 차단은 지금 문구(현재 화면에서 직접 편집 불가)를 유지한다.

실행 요약 띠의 한 줄은 그대로다. 실행 오류 다섯 가지(타임아웃 · 조건 불충족 · `CAPACITY_FULL` · `DEADLOCK` · `INTERLOCK_BLOCK`)는 실행 화면의 오류 칸과 「자세히」에 같은 세 줄로 나온다.

오른쪽 아래 알림 가운데 붙여넣기 · 삭제 · 연결 거절은 **무엇**과 **왜** 두 줄이다.

빈 목록은 기호, 한 줄, 다음 행동 단추다. 실행 중이라 못 하는 행동은 단추를 흐리게 하고 까닭을 적는다. 자재가 없을 때 「자재 추가」는 자재를 하나 만든다.

Evolution Lab, Workspace 파일 묶음, 자료 입력은 「준비 중」을 유지하고, 무엇을 할 화면인지와 지금 대신 쓸 수 있는 곳, 이동 단추를 보여 준다.

3D 장면과 64KB 이상 파일 가져오기는 150ms 뒤에 「불러오는 중」을 보여 준다. 그보다 빨리 끝나면 자리 표시를 띄우지 않는다.

판정, 차단 규칙, 오류 코드, `src/runtime/` 는 바꾸지 않았다.

## 문구 (전 → 후)

| 전 | 후 | 어디 |
|---|---|---|
| `[TIMEOUT_UNDEFINED]` 와 `수정 위치: …` 한 덩어리 | 무엇: 단계 이름 / 왜: 타임아웃 미정 / 어떻게: 3단계 Action 에서 값을 입력. 수정 위치 문구는 어떻게에 남김 | 6단계 준비 검사, 실행 차단 |
| 실행 오류 한 줄 `[CODE] message` | 무엇·왜·어떻게 세 줄. 요약 띠는 한 줄 유지 | 실행 오류, 자세히 |
| 가져오기 거부 문단 | 무엇: 가져오기 거부 / 왜: 파일을 열지 않음 / 어떻게: 격리 보관. 「확인」은 유지 | 가져오기 |
| 저장 실패 한 줄 | 무엇: 저장 실패 또는 임시 저장 실패 / 왜: 기존 문장 / 어떻게: JSON 내보내기 또는 저장본 | 저장, 임시 저장 |
| `실행 중에는 붙여넣기가 차단됩니다` 한 줄 | 무엇: 붙여넣기 불가 / 왜: 그 문장 | 알림 |
| `자기 자신과 연결할 수 없습니다` 한 줄 | 무엇: 연결 불가 / 왜: 그 문장 | 알림 |
| `실행 중에는 삭제가 차단됩니다` 한 줄 | 무엇: 삭제 불가 / 왜: 그 문장 | 알림 |
| `이 Workspace에 저장된 프로젝트가 없습니다…` | 같은 문장 + 새 프로젝트, 예제 | 홈, 프로젝트 파일 |
| `배치된 Substation이 없습니다…` | Unit이 없습니다. 팔레트의 빈 유닛을 놓으세요 + 단추 | 2단계 카드 보드, 트리 문구 |
| `물류 연결이 없습니다.` | 같은 문장 + 물류 연결 단추 | Unit이 있고 연결이 없을 때 |
| `자재 정의 없음` + 단추 | 자재가 없습니다 + 자재 추가 | 4단계 자재 |
| `단계가 없습니다.` | 시퀀스 단계가 없습니다 + 단계 추가(Action이 없으면 흐리고 까닭) | 4단계 시퀀스 |
| `Interlock 없음…` | Interlock이 없습니다 + Interlock 추가 | 3단계 |
| 빈 Gap 표 | 남은 Gap 이 없습니다 + 재분석 | 5단계 |
| `로그 없음…` | 실행 로그가 없습니다 + 실행 | 6단계 자세히 |
| `찾는 이름이 없습니다` + 지우기 | 같은 문장, 빈 화면 모양 | 공통 탐색 |
| `후보 없음` | 입력 후보가 없습니다 + 후보 추가 | 입력 후보표 |
| 준비 중 한 줄 | 준비 중 유지 + 화면이 하는 일 + 지금 대신 쓸 곳 + 이동 | Lab, 묶음, 자료 입력 |
