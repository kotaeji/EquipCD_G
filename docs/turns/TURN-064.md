# TURN-064 타이밍 차트 — 끝난 실행을 시간축 막대로

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.6.0` 그대로다. `README.md` 는 고치지 않았다. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

6단계 「자세히」에 탭 「타이밍 차트」를 더했다. 실행 기록만 읽는 순수 함수 `timingChart` 가 줄과 막대를 만들고, 그림은 SVG 다. 차트 라이브러리는 없다. 모델과 실행 엔진은 바꾸지 않았다.

- 막대 하나 = 단계 실행 한 번. 시작·끝은 「실행 결과 요약」과 같다. 건너뜀과 아직 시작하지 않은 단계는 그리지 않는다.
- 기본 줄은 Unit. 「Device 별」로 바꾼다. 개체가 둘 이상이면 「개체 별」이 나타나고, 막대 위의 번호로 개체를 구분한다. 개체마다 색을 바꾸지 않는다.
- 완료는 ✓, 진행 중은 ▶, 오류는 !, 정지는 △(점선 테두리). 신호 기다림과 여러 개체 대기는 빗금이다. 색만으로 구분하지 않는다.
- 막대에 초점을 주면 이름 · 시작 · 끝 · 걸린 시간 · 갈래 / 회차 · 개체 번호가 나온다. 막대를 누르면 요약 표의 그 줄에 「차트」가 붙고 그 줄이 강조된다.
- 눈금은 총 시간에 맞춰 0.5초 · 1초 · 2초 · 5초 가운데에서 고른다. 1× 는 긴 실행도 한 화면에 맞추고, 확대(2× · 4×)는 차트 안에서 가로로 스크롤한다. 진행 중이거나 일시정지면 「지금」 선이 있다.
- 실행 전에는 「실행 기록이 없습니다.」와 「실행」이다.
- 최신 main(TURN-061 · 062 · 065 · 066)을 merge 했다. 타이밍 차트 탭은 `ChartGantt`, 개체 별은 `Users`다. Unit · Device · 확대 · 축소 · 실행은 뜻 표에 있던 아이콘을 그대로 쓴다. 막대 안의 상태 기호는 그대로다. `tests/turn054.test.ts` 는 main 그대로다.
- 타이밍 탭을 연 동안만 자세히 높이를 280px 로 하고, 가운데 캔버스 최소 높이를 140px 로 낮춘다. 다른 탭은 150px 그대로다. 1280×800 에서 문서 스크롤은 0이다.

5공정 예제를 끝까지 돌리면 Unit 5줄에 막대 12개, 가상 시간 `00:11.100` 이다. 병렬 예제는 `00:02.500` 이고, S1 의 두 시퀀스 막대가 시간축에서 겹친다.

## 화면 (1280×800)

Chrome, CSS 뷰포트 1280×800, devicePixelRatio 1. 콘솔 오류 0. 문서 스크롤 0 (`scrollWidth` 1280, `scrollHeight` 800).

5공정은 끝까지 실행한 뒤 타이밍 탭이다. 눈금은 2초. S3 가공 막대가 가장 길다. 1× 에서 차트 가로 스크롤은 없고, 확대 2× 에서 차트 안 스크롤은 948px / 보이는 폭 560px 이다.

병렬 예제는 S1 듀얼 클램프에 두 갈래가 겹쳐 있고, S2 푸시는 그 뒤에 시작한다. 눈금은 0.5초.

## 하지 않은 것

- 차트에서 시간을 고치거나 실행을 되감기. 차트를 내보내기
- `README.md`, `release/` 재빌드, 의존성 추가, 실행 엔진 · 모델 변경

## 확인 필요

- 겹침과 병목이 한눈에 읽히는가(AC9)는 사람 검수다. 이 문서는 완료로 적지 않는다.
- 타이밍 탭이 열려 있는 동안만 실행 캔버스 최소 높이를 200px 에서 140px 로 낮춘다. 차트가 280px 를 쓰고도 문서가 스크롤되지 않게 하려는 것이다. 다른 탭의 자세히 높이는 150px 다.
- 여러 개체 대기는 기록의 `waitMs` 로 그린다. 이전 단계 끝과 이번 시작 사이에 들어가는 시간은 단계 앞에, 나머지는 단계 끝 위에 빗금으로 둔다. 아직 끝나지 않은 대기는 지금 시각까지 그린다.
- 신호 기다림은 Device 가 없다. Unit · Device 보기에서는 「신호 기다림」 줄에 둔다.
- 1× 는 플롯을 400px 안에 맞춘다. 11초 예제는 한 화면에 들어오고, 확대하면 차트 안에서만 가로로 스크롤한다.
