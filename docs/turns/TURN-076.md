# TURN-076 CSV 입력 · 표 붙여넣기 · IO 리스트 내보내기

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `README.md` 는 고치지 않았다. `release/` 는 다시 빌드해 커밋하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

「자료 입력」에서 XLSX 와 같은 미리보기 → 열 매핑 → 후보 만들기로 CSV 파일도 읽는다. 구분 문자는 쉼표 · 세미콜론 · 탭을 표의 앞부분에서 고른다. UTF-8 BOM 은 떼고, 따옴표 안의 쉼표 · 줄바꿈 · 겹따옴표(`""`)는 한 칸으로 읽는다. 같은 칸에 엑셀에서 복사한 글을 붙여 넣으면 시트 이름 「붙여넣기」로 같은 흐름에 들어간다. 파일은 이 브라우저 안에서만 읽고 업로드하지 않는다.

한도는 XLSX 와 같다. 5MB 를 넘거나 5,000줄을 넘으면 읽지 않고 세 줄(무엇 · 왜 · 어떻게)로 알린다. EUC-KR 이나 UTF-16 처럼 UTF-8 이 아닌 바이트는 글자를 지어 넣지 않고 「UTF-8 로 저장해 주세요」로 거부한다. 거부되면 모델과 후보표는 그대로다. 후보를 만들어도 Unit · Device 수와 rev 는 그대로이고, 반영은 입력 후보표에서 확인한 것만이다.

형식 표는 XLSX · CSV 「지원(IO 리스트 · 사양표)」, PDF · DWG · USD 「추출 미구현」이다.

「IO 리스트 내보내기 (CSV)」는 1단계 입력 후보표와 5단계 Export 미리보기에 있다. 신호 한 줄에 Unit 이름, Device 코드, Device 이름, 종류, 신호 이름, 방향(입력/출력), 역할, 주소, 주소 상태(미지정/가정/확인), 메모를 적는다. 파일은 UTF-8 BOM, 쉼표, 필요한 칸만 따옴표다. 머리글은 자료 입력의 열 추측이 알아보는 이름이라, 내보낸 파일을 다시 넣으면 열 열 개가 모두 매핑되고 후보가 모두 「이미 있음」이다. 내보내기 클릭은 모델을 쓰지 않는다. rev 와 Undo 는 그대로다.

신호에는 메모 필드가 없어 메모 칸은 빈 칸이다. 역할과 주소 상태 열은 다시 넣으면 의미로 잡히지만, 후보는 그 글자로 기존 신호를 고치지 않는다.

새 글자 크기는 `src/ui/csv-intake.css` 에만 두었고 `--fs-*` · `--sp-*` 만 썼다. 내보내기 단추의 아이콘은 기존 `export-json`(Download) 이다.

## 확인 필요

- AC10 은 Matthew 검수 전이다. 실제 IO 리스트를 이 열로 주고받을 수 있는지는 사람 검수다.
- 메모 칸은 신호 필드가 없어 빈 칸으로 나간다. 다시 넣어도 메모는 후보 출처 글에만 남고, 비어 있으면 남지 않는다.
- 역할 · 주소 상태 열은 매핑되지만 후보가 「이미 있음」이면 기존 신호의 역할과 주소 상태를 바꾸지 않는다. 주소 글자는 확인 뒤 반영할 때만, 지금 규칙대로 가정 주소로 채워진다.
- UTF-8 로 해석되지 않는 바이트만 거부한다. UTF-8 로 우연히 읽히는 다른 인코딩은 따로 가리지 않는다.
- 도움말의 자료 입력 문장은 이 TURN 에서 고치지 않았다. 화면 본문과 다를 수 있다.
