# TURN-038 단계 바 배지에서 남은 항목을 보고 바로 고치러 간다

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.3.1`. `release/` 는 다시 빌드하지 않았다. `README.md` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

단계 바 여섯 단추에 상태 낱말과 남은 항목 수가 보인다. 이름 부분을 누르면 그 단계로 가고, 배지를 누르면 그 단계의 남은 항목 목록이 열린다. 지금 단계가 아니어도 열리고, 단계는 바뀌지 않는다.

- 상태 낱말은 필수 누락, 재확인 필요, 필수 충족, 확인됨이다. 기호(× △ ○ ✓)를 같이 그린다.
- 항목을 누르면 그 단계와 하위 탭으로 가서 대상(Unit, Device, 자재, 단계)을 고르고, 고칠 칸을 보이게 한 뒤 약 2초 동안 테두리로 강조한다. 입력 칸이면 초점도 준다. 목록은 닫힌다.
- `evaluateSteps` 가 내는 항목 종류 24개 모두에 이동 대상을 붙였다. 이동할 화면이 없는 경우에는 목록에 「이동할 화면 없음」을 적는다. 판정의 level, ready, fingerprint 는 그대로다.
- 예: 자재 정의 없음 → 4 자재·Flow, 시퀀스 단계 없음 → 4 Station 시퀀스, 입력 후보 확인 대기 → 1 입력 후보표, 실행 전 검사 미통과 → 5 점검, 아직 실행하지 않음 → 6 실행·저장, 저장되지 않은 변경 → 위 「저장」 단추.
- 맨 아래 「남은 항목 N」은 지금 단계의 같은 목록을 연다. Esc 와 바깥 누름으로 닫힌다. 배지와 항목은 단추라 키보드로 열고 이동한다.
- 이동과 강조는 보기만 바꾼다. 모델 rev 와 Undo 는 그대로다. 실행 중에도 목록과 이동이 되고, 실행 상태와 가상 시간은 바뀌지 않는다.
