# TURN-096 Unit 복제 · 고른 것 정렬과 간격 맞추기

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.10.0`. `README.md` 는 고치지 않았다. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

Unit 을 고르고 「복제」(도구 줄 · 우클릭 · Ctrl/Cmd+D)하면 그 Unit 안의 Device · 신호 · 포지션 · Action · Unit 안쪽 신호 연결이 새 ID 로 생긴다. 이름은 「이름 사본」, 같은 이름이 있으면 「이름 사본 2」. 코드는 비어 있는 다음 `S` 번호다. 사본은 원본 오른쪽 빈 자리에 놓이고, 다른 Unit 과 겹치면 사본만 오른쪽으로 밀린다. 위치 잠금은 풀린 채로 생긴다. 한 번에 여러 Unit 을 골라도 rev +1, Undo 한 번이다.

복사하지 않는 것: Unit 사이 물류 연결, 다른 Unit 과의 신호 연결, Station 시퀀스 단계, 자재 경로. 고른 Unit 에 Substation 시퀀스가 있으면 확인 창이 뜨고, 「Substation 시퀀스도 복사」를 켜면 그 시퀀스와 흐름 블록이 새 ID 로 복사된다. 시퀀스가 없으면 확인 없이 바로 복제한다.

Unit 을 둘 이상 고르면 「배치 ▾」에 「고른 것만 자동 정렬」이 있다. 고른 Unit 만 물류 순서대로 왼쪽부터 나란히 놓고, 고르지 않은 Unit 은 그대로다. 잠긴 Unit 은 움직이지 않고 「잠긴 Unit N개는 제외」가 보인다.

같은 Unit 의 Device 를 둘 이상 고르면 「배치 ▾」의 가로/세로 간격 같게 · 너비/높이 같게가 Device 에도 듣는다. 좌/상 정렬은 원래 도구 줄 단추가 Device 에도 듣는다. Device 가 Unit 밖으로 나가면 Unit 이 커진다. 잠긴 Unit 은 커지지 않고 Device 가 안쪽에 남는다. 명령 찾기와 단축키 목록에 「고른 것만 자동 정렬」을 넣었다.

포인터: 탐색기에서 S2 줄 클릭, 「더 보기」→「복제」. 사본은 `S6 S2 식별 사본`, rev 1→2, 원본 오른쪽에 겹치지 않게 놓인다. 이 너비에서는 「복제」가 도구 줄 넘침(「더 보기」) 안에 있다. 이어서 1단계 센서 카드를 누르고 S1 을 고른 뒤 「프로젝트에 추가」, 도면에서 PSH-01 클릭 후 Ctrl+A, 「배치 ▾」→「가로 간격 같게」. 고른 Device 3개가 한 줄 간격으로 놓이고 rev 3, Undo 2 다. 화면 맞춤은 `0`, 확대는 「확대」로 150% 다. 라이트/다크는 테마 라디오다.

## 하지 않은 것

- Unit 을 다른 프로젝트로 복사, 물류 연결까지 복제, 격자 스냅 변경
- 3D · 카드 보드에서의 정렬
- `README.md`, `release/` 재빌드, 의존성 추가, 범위 밖 리팩터링
- 실행 규칙 · 파일 형식 버전. 프로젝트 파일에 새 필드를 넣지 않았다. `lineage.duplicatedFrom` 은 기존 선택 필드다.

## 확인 필요

- 같은 Substation 을 여러 개 빨리 만들 수 있는지는 사람 검수(AC9)다. 이 문서는 완료로 적지 않는다.
- Substation 시퀀스가 있을 때만 확인 창을 연다. 시퀀스가 없으면 Ctrl/Cmd+D 한 번에 복제된다.
- 고른 Unit 정렬은 물류 연결의 위상 순서다. 순환이면 지금 왼쪽부터의 순서를 유지한다. 잠긴 Unit 과 고르지 않은 Unit 은 밀지 않고, 움직이는 Unit 만 오른쪽으로 비킨다.
- 로컬 `npm run typecheck` 와 `npm test` 를 돌렸다. CI 판정은 이 기록이 아니다.
