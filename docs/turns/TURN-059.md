# TURN-059 배경 도면(PNG · JPEG) · 축척 맞춤 · Unit 잠금

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0` (버전을 올리지 않았다). 실행 규칙은 `seq-runtime/0.6.0`. `release/` 와 `README.md` 는 바꾸지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

2단계 도면 도식의 도구 줄에 「배경 도면」을 두었다. PNG 또는 JPEG 한 장을 고르면 도면 뒤에 깔리고, 확대 · 이동을 도면과 함께 따른다. 그림은 프로젝트 안의 데이터 URL 이고, 없는 예전 파일은 그대로 열린다.

- 한도: 파일 2MB, 긴 변 4096px. 넘거나 그림이 아니면 넣지 않고, 무엇 · 왜 · 어떻게 세 줄로 알려 준다. 모델은 그대로다.
- 조절: 불투명도 10~100%, 위치, 배율(mm/px). 두 점 축척 맞춤은 그림 위 두 점의 픽셀 거리를 실제 mm 로 나눈다. 200px = 1000mm 이면 배율 5.
- 「배경 잠금」은 기본으로 켜져 있다. 잠겨 있으면 선택 · 이동되지 않고 클릭이 뒤의 도면으로 지나간다. 바꾸기와 지우기(확인 창)가 있다. 넣기 · 바꾸기 · 지우기 · 조절은 각각 rev +1, Undo 한 번.
- 「레이어」의 배경을 끄면 그림도 숨는다. 지우지는 않는다. 카드 보드, 6단계 도면, 3D 에는 나오지 않는다. 미니맵 · 화면 맞춤 · 자동 정렬 · 겹침 검사는 배경을 노드로 세지 않는다.

Unit 마다 「위치 잠금」이 있다. 속성 칸, 우클릭 메뉴, 도구 줄, 그리고 「모두 잠금」 · 「모두 풀기」. 잠긴 Unit 은 끌기 · 방향키 · 정렬 · 간격 · 겹침 풀기 · 크기 조절로 움직이지 않는다. 안의 Device 이동 · 연결 · 속성 · 삭제(확인 창)는 된다. 여러 개 정렬 · 간격에서 잠긴 것은 빠지고 「잠긴 Unit N개는 제외」가 나온다. 도면에는 자물쇠 기호와 접근성 이름 「위치 잠금」이 있다. 잠금은 선택 필드로 저장된다.

## 화면

Headless Chrome. 1280×800. 기기 픽셀 배율 1. 콘솔 오류 0. 문서 스크롤 0. 예제는 5공정. 배경은 파란 격자 도면 한 장.

- 배경을 깐 도면. 라이트: `TURN-059-bg-light-1280.png`
- 같은 화면, 다크: `TURN-059-bg-dark-1280.png`
- 두 점 축척 맞춤. 두 점 거리와 실제 거리 1000mm. 라이트: `TURN-059-scale-light-1280.png`
- 같은 화면, 다크: `TURN-059-scale-dark-1280.png`
- 잠긴 Unit. 도구 줄은 「위치 잠금 해제」. 라이트: `TURN-059-lock-light-1280.png`
- 같은 화면, 다크: `TURN-059-lock-dark-1280.png`

- 그림에서 장비를 알아보기, 그림 위에 주석
- Device 잠금, Unit 안의 Device 를 서브플로로
- 실행 · 시퀀스 · 3D 변경
