# TURN-078 움직임 규칙 하나로 · 실행 도면의 상태 표현

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.6.0`. `release/` 는 다시 빌드하지 않았다. `README.md` 는 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

화면이 바뀌는 시간과 곡선을 세 칸 · 두 곡선으로 모았다. 6단계 도면은 실행 상태에서 진행률, 물류선 위 자재, 기다림, 방금 끝남을 기호와 함께 그린다. 실행 엔진 · 가상 시간 · 로그는 그대로다.

### 움직임 규칙

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--dur-1` | 120ms | 단추 · 카드 테두리, 탭 색 |
| `--dur-2` | 200ms | 접기 / 펼치기, 창 · 메뉴 · 알림이 들어옴 |
| `--dur-3` | 320ms | 이동 강조(TURN-038), 방금 끝남 한 번 |
| `--ease-enter` | 들어올 때 감속 | 열림 · 나타남 |
| `--ease-exit` | 나갈 때 가속 | 접힘이 닫힘 |

`prefers-reduced-motion` 이거나 「동작 강조」 또는 「설비 동작」이 꺼지면 전환과 도면의 움직임을 없애고, ▶ 진행 중 · ○ 대기 · ✓ 완료 기호와 글자는 남긴다. 판정은 `diagramMotionOn` 이고, 줄이기는 `scene/motion.ts` 의 `prefersReducedMotion` 과 같다.

예외는 하나다. 신호선의 흐르는 점선(`.react-flow__edge-path.rf-sig-on`, `rf-sig-flow 0.8s linear infinite`)은 상태 전환이 아니라 계속 도는 표시다. 줄이기와 `data-motion="off"` 에서는 이것도 멈춘다.

### 실행 도면

계산은 `src/ui/runDiagram.ts` 에 있다. 같은 가상 시각은 같은 그림이다. 진행률 갱신은 기존 실행 루프의 프레임 한 번이다. 16x 도 그 프레임에서 한 번만 상태를 바꾼다.

- 진행 중 Device 는 (지금 − 시작) ÷ (완료 예정 − 시작) 이다. 아래에 막대가 차고, 옆에 퍼센트가 있다. 일시정지는 그 숫자에서 멈춘다.
- 자재를 옮기는 Action 동안 표식은 물류 연결의 매끄러운 꺾임 선 위에 있다. 연결이 없으면 손잡이 사이 직선이다. 움직임이 꺼지면 지금 Unit 에 머문다.
- 기다리는 Unit / Device 는 ○ 대기와 점선 테두리다. 깜박이지 않고, 조금 흐리다. 일시정지와는 따로다.
- 끝난 Device 는 가상 시간 `--dur-3`(320ms) 동안 한 번 강조된 뒤 ✓ 완료로 남는다. 움직임이 꺼지면 강조 없이 완료만 보인다.

배속 목록에 16x 를 더했다. 논리 결과는 배속의 영향을 받지 않는다.

## 확인 필요

- 움직임이 과하지 않고 흐름이 읽히는가(AC9)는 사람 검수다. 이 문서는 완료로 적지 않는다.
- TURN-054 는 100% 배율에서 상태 낱말을 숨겼다. 실행 중 기호는 그 배율에서도 남긴다. 이름과 포트 낱말은 120% 부터다.
- 「동작 강조」와 「설비 동작」 칸은 도면에서 여전히 꺼진 모양이다(3D 에서 켠다). 값은 도면에도 적용된다. 운영체제의 움직임 줄이기가 켜져 있으면 「설비 동작」이 처음부터 꺼져 도면 움직임도 없다.
