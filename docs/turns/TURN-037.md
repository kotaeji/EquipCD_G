# TURN-037 6단계 도면을 가운데 칸에 맞추고 「자세히」를 한 줄로

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.3.1`. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

6단계 「도면」은 장비 전체를 가운데 칸에 맞춰 그린다. 2단계 도면 도식의 맞춤(여백, 최소 확대 0.5, 최소 확대일 때 왼쪽 정렬, 처음 한 번만 맞춤)은 그대로다.

- 처음 열 때, 「3D」에서 「도면」으로 돌아올 때, 가운데 칸 크기가 바뀔 때 다시 맞춘다. 칸 크기는 탐색기, 「단계」, 「가동 조건」, 「자세히」 접기/펼치기와 창 크기 변경이다.
- 맞춤 여백은 위 44px, 오른쪽 12px, 아래 16px, 왼쪽 12px 이다. 위는 28px 범례를 비운다. 확대는 0.05–2 이다. 최대 확대 2에 걸리면 칸의 70%를 채우지 않아도 된다.
- 사용자가 줌이나 이동을 한 뒤에는 칸이 바뀌어도 그 보기를 유지한다. 「화면 맞춤」이 지금 칸에 다시 맞추고, 그 다음 칸 변화는 다시 따라간다.
- 6단계 맞춤은 `UserView.zoom` 에 쓰지 않는다. 2단계 확대 표시와 2단계 맞춤은 6단계를 다녀와도 그대로다.
- 「자세히」 단추는 줄바꿈하지 않고, 글자 너비 아래로 줄어들지 않는다. 접힌 머리의 로그 한 줄이 길어도 단추 글자는 한 줄이다.

실행 중에 다시 맞춰도 뷰포트만 바뀐다. 실행 상태, 가상 시간, 단계 기록, rev 는 건드리지 않는다.

## 확인 필요

- 도면 크기가 보기 좋은가는 사람 검수(Matthew)다. 이 문서는 완료로 적지 않는다.
- 1280×800 에서 Unit 상자는 가운데 칸 폭의 약 96%를 쓴다. 미니맵(160×110)은 오른쪽 아래 가장자리에 걸친다. 칸이 넓고 「자세히」가 펼쳐져 세로가 짧으면 오른쪽 Unit 아래가 미니맵과 더 겹친다.
- 6단계의 전체 보기 아이콘은 뺐다. 같은 역할은 오른쪽 위 「화면 맞춤」이다. 확대 · 축소 단추는 남아 있다.
