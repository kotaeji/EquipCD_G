## 한 일

1. `docs/user-manual/USER-MANUAL.ko.md` 를 `main` `4bc0f6a` 화면으로 다시 썼다. 절은 0부터 16까지 순서대로이고, 그 뒤는 부록 A~D다. 이전의 19·20·21절 섞임은 없다.

3. 그림을 개발 서버에서 다시 찍었다. Chrome 156.0.8078.47, CSS 뷰포트 1280×800, devicePixelRatio 1, 라이트. 다크는 화면 구성과 Workspace 탭 두 장이다. 쓰지 않는 이전 그림은 지웠다.
4. 실습 세 개를 빈 저장소에서 처음부터 끝까지 따라 했다. 결과는 아래 표.

## 확인 필요

- AC10은 Matthew 검수 전이다. 이 문서는 완료로 적지 않는다.
- 기능 목록 FL-09는 탭 닫기와 Workspace 전환을 같은 세 단추(저장 후 닫기 / 저장하지 않고 닫기 / 취소)로 적는다. 지금 코드에서 그 세 단추는 탭 닫기에 있다. 저장하지 않은 편집이 있으면 Workspace 전환은 「저장하러 돌아가기」만 있는 차단 창이다. 기능 목록은 고치지 않았다.
- 단계 단추의 판정 배지는 DOM에는 있고 화면에서는 1픽셀로 숨겨져 있다. 눈으로 보는 판정은 상태 줄의 「남은 항목」이다.
