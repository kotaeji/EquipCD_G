# TURN-029 3D 시뮬레이션 화면 — 가운데 3D · 왼쪽 정보 · 오른쪽 가동 조건

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.3.1`. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

- 6단계 「실행·저장」에 「도면 / 3D」를 넣었다. 고른 보기는 이 브라우저의 UserView(`runView`)에만 남고 프로젝트 파일에는 들어가지 않는다.
- 3D 를 고르면 작업 영역이 왼쪽 정보, 가운데 3D, 오른쪽 가동 조건이 된다. ▶ 실행 · 일시정지 · 재개 · +0.1s · 초기화 · 끝까지 · 배속은 2D 와 같은 실행 상태를 본다.
- 장면에 무엇을 놓을지는 `describeScene` 이 계산한다. Three.js 는 그 결과를 그리기만 한다. 도면 x 는 3D x, 도면 y 는 3D z 다.
- Device 형상은 에셋 14종마다 직육면체 · 원기둥 조합이 정해져 있다. 모르는 종류는 기본 상자다. CAD · 외부 모델은 쓰지 않는다.
- 실행 중인 단계의 Device 는 색과 윤곽(바닥 고리)으로 강조한다. 오류로 멈춘 Device 는 위험색과 표식이다. 자재는 지금 있는 Unit 가운데에 놓인다.
- 카메라: 끌어서 회전, 오른쪽 끌기 또는 Shift+끌기로 이동, 휠 확대, 화살표 회전, +/− 확대, Home 과 「전체 보기」.
- 오른쪽에서 Action 동작 시간을 바꾸면 기존 `setQuantity` 로 모델이 바뀐다. rev +1, 실행 취소 한 번에 복귀, 「가정」 표시는 남는다. 실행 중 · 일시정지 중에는 그 입력이 잠기고 이유가 보인다. 배속 · 이름 표시 · 동작 강조는 바뀐다.
- 「이 화면에 들어온 뒤 바꾼 값 되돌리기」는 이 화면에서 넣은 동작 시간 편집만 실행 취소한다. 그 위에 다른 편집이 있으면 그 편집은 남기고, 묻힌 동작 시간은 같은 `setQuantity` 로 원래 값에 맞춘다.
- WebGL 을 쓸 수 없으면 「이 브라우저에서는 3D 를 그릴 수 없습니다」와 「도면으로 보기」가 나오고 앱은 죽지 않는다.
- 의존성은 `three` 와 개발용 `@types/three` 만 늘었다. `three` 0.187 배포본에 타입 선언이 없어 `@types/three` 를 devDependencies 에 두었다.

## 하지 않은 것

- 3D 에서 배치를 고치거나 여러 프로젝트를 한 장면에 두기
- 파일 형식 · 런타임 규칙 변경, 모델에 없는 가동 조건(컨베이어 mm/s 등)
- 2D 실행 화면의 구성 변경, 사용자 매뉴얼, 기능 목록

## 검토 반영

루카 검토에서 3D 가 작게 보여 이름 · 강조 · 자재가 읽히지 않았다. 같은 브랜치에서 고쳤다.

- 이름표는 화면 픽셀로 그린다. Unit 이름은 14px, Device 이름은 12px. 겹치면 Device 이름을 숨긴다.
- 「전체 보기」는 장면의 가로 또는 세로가 화면의 약 88% 를 채우게 거리를 잡는다. 3D 칸은 왼쪽 200px · 오른쪽 220px 를 빼고 나머지를 써서, 1280×800 에서 작업 영역의 절반보다 넓다. 양옆은 「접기」로 더 줄일 수 있다.
- Device 몸체는 발자국 중심을 유지한 채 키우고, 초록(성공색)으로 바닥과 구분한다. Unit 구역은 테두리로 나뉜다. 물류는 화살촉이 있는 막대다.
- 동작 중은 경고색 몸체와 「▼ 동작 중」, 오류는 위험색과 「오류」다. 자재는 큰 상자와 「이름 · 상태」다.
- 왼쪽 정보의 실행 상태는 한글이다. 단계 이름은 줄바꿈되고 `title` 에 전체가 있다.
- 스크린샷 10장을 다시 찍었다.

## 확인 필요

- 형상은 종류를 구분하는 기본 도형이다. 도면 그림과 1:1 이 아니다.
- 동작 중 몸체는 경고색이고, 그 위에 「▼ 동작 중」이 있다. 평소 몸체는 성공색이라 회색 바닥과 구분된다.
- 숫자 칸에 이어서 치면 같은 Action 의 마지막 「3D 동작 시간」 편집을 한 번의 실행 취소로 덮어 쓴다. 다른 Action 으로 바꾸면 실행 취소가 하나 더 쌓인다.
- 되돌리기 단추는 이 화면에 들어온 뒤의 동작 시간만 되돌린다. 그 사이에 넣은 다른 편집(오류 주입, 이름)은 남는다.
- 단일 HTML 빌드 크기: 바꾸기 전 `release/equipment-concept-designer.html` 4,205,511바이트(main `3cde2e5`), `three` 를 넣은 뒤 4,777,026바이트(+571,515). 외부 script/link 참조는 없다. 이 브랜치는 `release/` 를 커밋하지 않는다.
