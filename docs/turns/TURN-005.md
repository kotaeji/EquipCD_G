# TURN-005 도면 캔버스 React Flow

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식 `0.2.0` 과 실행 규칙은 바꾸지 않았다. `release/` 는 다시 빌드해 커밋하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

「도면 도식」과 실행 단계 캔버스를 `@xyflow/react` 로 그렸다. 직접 그리던 `svg.canvas-svg` 는 없다. 노드와 엣지는 매 렌더 `Project` 에서 만들고, 끌기 중의 좌표는 화면에만 있다. 놓으면 기존 `onMoveCommit` 을 한 번 부른다. 모델 좌표와 React Flow 좌표는 1:1 이고, 확대·이동은 뷰포트에만 있다. `view.zoom` 은 뷰포트 확대율과 맞춘다.

의존성은 `@xyflow/react` 하나다. `style.css` 는 가져오지 않고 `dist/base.css` 만 가져온다. 색은 기존 토큰만 쓴다. 새 색 리터럴은 Unit·컨트롤 그림자 `rgba(16, 24, 40, .06)` 뿐이다.

휠 확대는 0.5–2, 빈 곳 드래그로 이동, 미니맵, 확대·축소·전체 보기 컨트롤을 넣었다. 더블클릭 확대는 규격에 없어 껐다.

선택 표시는 링만 쓴다. 쌓임은 Unit 1, 선택 Unit 2, 물류·신호 엣지 3, Device 3, 선택 Device 6, 자재 8 이다. `zIndexMode` 는 `manual` 이라 선택이 이 숫자를 더 올리지 않는다. 그래서 선택한 Unit 이 자기 Device 와 신호선을 가리지 않는다.

범례는 왼쪽 위 가로 한 줄, 높이 28px, 항목 4개다. 「배경: 도면/VC 탑뷰 없음…」은 범례 문장에서 빼고 그 Panel 의 `title` 툴팁으로 두었다. 처음 `fitView` 여백은 위 48px, 오른쪽 188px, 아래 140px, 왼쪽 52px 이다. 범례(28px), 컨트롤(28px), 미니맵(160×110)과 패널 여백 15px 를 비운 값이다. 맞춤 결과가 최소 확대 0.5 에 걸리면 가운데로 두지 않고 왼쪽 정렬한다. 가장 왼쪽 노드의 화면 x 가 왼쪽 여백 52px 이고, 세로는 맞춤이 잡은 가운데를 유지한다. 잘리는 오른쪽은 미니맵과 이동으로 본다. 다 들어가는 경우(실행 단계)는 가운데 맞춤 그대로다. 1280×800 배치 화면은 50% 에 걸린다. 그 다음 사용자가 옮기거나 확대하면 겹쳐도 된다.

`diagramOpen` 은 확대율이 바뀌어 부모가 다시 그려질 때, 제어되는 `open={false}` 가 사용자가 연 도면을 바로 닫지 않게 연 상태를 유지한다. 접기 위치는 그대로다.

## 하지 않은 것

- 핸들을 끌어 연결하기, 연결 규칙 안내
- Unit 안에 Device 를 서브플로로 두기, 소속 이동 영향 검사 변경
- 배치·연결 단계의 카드 보드, 도면 접기 위치
- 프로젝트 JSON, 파일 형식, rev, Undo 규칙, 실행 엔진
- 헤더, 탭 바, 스텝퍼 색
- `release/` 재빌드 커밋
- 사람 검수

## 확인 필요

- AC12 사람 검수는 Matthew 몫이다. 이 문서는 완료로 적지 않는다. 처음 맞춤이 50% 라 머리띠 글자가 작다. 이번 검토에서 키우지 말라고 한 항목이라 그대로 두었다.
- 미니맵 마스크는 라이브러리가 뷰포트 바깥에 칠한다. 색은 `--canvas` 를 0.7 로 푼 값이다.
- React Flow 표시(attribution)는 숨기지 않았다. 미니맵과 겹치지 않게 오른쪽 위로 옮기고 토큰으로만 칠했다.
- 더블클릭 확대는 끄다. 자재 미니맵 색은 `--warning` 이다.
