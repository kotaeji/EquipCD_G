# TURN-066 대상 찾기 — 이름으로 Unit · Device · 신호 · Action 찾아가기

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `README.md` · `release/` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 바뀐 조작

1. 명령 찾기(Ctrl/Cmd+K)에 글자를 치면 「대상」이 종류별로 나온다. 글자가 없으면 지금처럼 명령만 나온다. 종류는 Unit · Device · 신호 · 포지션 · Action · 단계 · 블록 · Interlock · 자재 · Gap 이고, 종류마다 5줄까지 보인 뒤 「N개 더」가 나머지를 연다.
2. `>` 로 시작하면 명령만, `@` 로 시작하면 대상만 찾는다. 창 아래에 그 안내가 있다.
3. 줄에는 이름, 코드, 종류, 위치(「S1 투입 › CYL-01」)가 있다. 이름 · 코드 · 화면 이름의 부분 일치이고, 띄어쓰기와 대소문자는 가리지 않는다.
4. Enter 는 그 대상을 고르고 맞는 단계 · 탭으로 옮겨 약 2초 강조한다. Unit · Device 는 2단계 도면, 신호 · 포지션 · Action · Interlock 은 3단계, 단계 · 블록은 4단계 흐름 표, 자재는 4단계 자재, Gap 은 5단계다. Shift+Enter 는 단계를 옮기지 않고 고르기만 한다.
5. 헤더 단추와 단축키 목록의 문구는 「명령 · 대상 찾기」다.

찾기와 이동은 모델을 읽기만 한다. rev · Undo 는 바뀌지 않고, 실행 중에도 찾아갈 수 있다.

## 한 일

- 색인은 `src/ui/objectFind.ts` 의 순수 함수다. 대상 1,000개에서 한 번 찾기는 로컬에서 50ms 안쪽이었다.
- 창은 `CommandPalette.tsx` 다. 새 글자 · 간격은 `CommandPalette.css` 에만 두고 `--fs-*` · `--sp-*` 만 썼다. `styles.css` 는 그대로다.
- 강조는 TURN-038 의 `itemJump` 다. 도면 칸과 흐름 블록 칸에 `data-jump` 를 달았고, 숨은 탭의 같은 칸보다 보이는 칸을 고른다.

## 하지 않은 것

- 글 바꾸기 · 정규식 · 속성 값으로 찾기 · 최근 찾은 것 · 다른 프로젝트까지 찾기
- 실행이 끝난 뒤의 실행 Gap (모델에 없는 줄). 모델에서 계산한 Gap 은 찾는다.

## 확인 필요

- AC9 「찾고 싶은 것이 바로 나오는가」는 Matthew 검수 전이다. 이 문서는 완료로 적지 않는다.
- Substation 시퀀스의 단계는 4단계 「Substation 시퀀스」 탭으로 간다. Station 흐름 표에는 그 줄이 없다.
- 화면 이름은 도면에 보이는 짧은 이름, 에셋 이름(예: 실린더), 포트 낱말, 블록 제목, Interlock 한 줄이다.
