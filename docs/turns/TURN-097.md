# TURN-097 3D 프레임 시간 테스트가 흔들리지 않게 하기

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `src/` 는 고치지 않았다. `README.md` 는 고치지 않았다. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

`tests/turn086.test.ts` 의 AC7 단정을 프레임 시간 비에서 구조 수로 옮겼다. 품질을 끈 장면과 켠 장면이 한 프레임에 하는 일을 `root.traverse` 로 센다. 같은 입력이면 이 수는 언제나 같다.

- `updateMatrixWorld` 가 도는 객체 수: 끈 쪽 421, 켠 쪽 425. 425 ≤ 421 × 1.2(505.2).
- 그리기 대상(Mesh · LineSegments) 수: 끈 쪽 360, 켠 쪽 364. 364 ≤ 360 × 1.2(432).

시간(before / after / ratio)은 예전과 같은 `console.log` 로만 남긴다. `expect` 는 `performance.now` 로 잰 값을 쓰지 않는다.

품질 쪽에 Mesh 85개를 더해 한 번 돌렸다. 85개는 끈 쪽 421개의 20%(84.2개)를 넘는다. 객체 수는 510이 되어 단정이 실패했다: `expected 510 to be less than or equal to 505.2`. 그 실행의 그리기 대상은 360에서 449로, 432를 넘었다. 객체 수 단정이 먼저 실패해서 그리기 대상 단정 줄은 실행되지 않았다. 85개를 더한 코드는 커밋하지 않았다.

로컬 확인이다. 통과 판정은 CI 를 따른다.

- `npx vitest run tests/turn086.test.ts` 를 50번 연속 돌렸고 50번 통과했다. `TURN-086 frame ms before=… after=… ratio=…` 로그가 50번 모두 나왔다. 시간 비는 0.660~1.715 였고, 1.2 를 넘은 회는 2회(1.347, 1.715)다. 구조 단정은 그 회에도 통과했다.
- `npx vitest run` 을 10번 연속 돌렸고 10번 모두 160파일 1228개 통과했다. AC7 실패는 없었다. 시간 로그는 10번 모두 나왔다. 그 10번의 시간 비는 0.634~1.108 이었다.

`npx tsc --noEmit` 도 로컬에서 통과했다. 이 문서는 완료로 적지 않는다.
