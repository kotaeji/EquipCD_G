# TURN-092 조건으로 도는 반복

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.11.0`. `README.md` 는 고치지 않았다. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 실행 규칙 (seq-runtime/0.11.0)

1. 반복 방식은 셋이다. 필드가 없으면 지금의 횟수 반복이다(1~10). 「참이 될 때까지」는 몸통을 한 번 돌고 조건을 본다. 「참인 동안」은 먼저 조건을 본다. 처음부터 거짓이면 몸통을 한 번도 돌지 않는다.
2. 조건 방식의 상한은 필수다. 기본 10, 범위 1~999. 비우면 미정이고 실행 전 차단이다. 상한에 닿으면 `LOOP_LIMIT` 로 멈추고 세 줄 안내가 나온다. 끝없이 돌지 않는다.
3. 회차마다 `LOOP_ITER`. 조건으로 끝나면 `LOOP_EXIT`(회차 · 조건 한 줄). 횟수 반복의 로그 문장은 그대로다.
4. 조건 미정 · 상한 미정도 실행 전 차단이다. 「이동」은 그 반복 줄로 간다. 몸통의 어떤 Action 도 그 조건을 바꾸지 못하면 조건 검사에 안내가 뜬다. 실행을 막지는 않는다.
5. 여러 개체는 개체마다 조건을 본다. Substation 시퀀스 안의 반복도 같은 방식이다.
6. 같은 모델 · 같은 조작은 같은 로그를 낸다. 실행 규칙 버전은 `seq-runtime/0.11.0` 이다. 파일 형식은 `0.3.0` 이다. 예제 3종은 방식 · 조건 · 상한 칸이 없어 저장 바이트와 실행 시각이 그대로다.

## 한 일

- 흐름 표의 반복 줄에서 방식을 횟수 / 참이 될 때까지 / 참인 동안으로 바꾼다. 한 번이면 rev +1 이고 Undo 한 번으로 돌아온다. 조건은 분기 · 재시도와 같은 편집기이고 자재 종류도 된다.
- SFC 되돌림 선은 횟수 반복이면 `×N`, 조건 반복이면 조건 글과 `최대 N` 이다.
- 상한에 닿은 실행은 실행 화면의 세 줄 안내와 로그 `LOOP_LIMIT` 를 남긴다. 「이동」은 그 반복 줄로 간다.

## 하지 않은 것

- 상한 없는 반복, 반복 중간 탈출, 중첩 깊이 변경, 글로 쓰는 조건
- `README.md`, `release/` 재빌드, 의존성 추가, 사용자 매뉴얼

## 확인 필요

- 조건 반복을 만드는 조작이 쉬운지는 사람 검수(AC10)다. 이 문서는 완료로 적지 않는다.
- 조건 칸이 좁아 상한 글자가 입력 칸 위에 줄바꿈된다. 값과 한 줄 식은 그 줄에 있다.
- 자재 종류는 실행 중에 바뀌지 않으므로, 그 조건의 반복에는 안내가 뜬다. 상한까지 돈다.
- `README.md` 와 사용자 매뉴얼의 규칙 표기 `seq-runtime/0.10.0` 은 이 TURN에서 고치지 않았다.
