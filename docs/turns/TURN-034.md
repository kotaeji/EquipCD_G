# TURN-034 흐름 표 다듬기 — 정지 표시 · 낱말 통일 · 이름 중복 · 병렬 갈래 나누기

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.3.1`. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

- 흐름 표와 접는 칸 단계 표는 한 단계의 기록을 `aggregateStepStatus` 로 모은다. 우선순위는 오류 > 진행 중 > 정지 > 완료 > 건너뜀 > 대기다. 낱말은 `stepStatusLabel` 이다. 흐름 표의 「실행 중」은 「진행 중」이다. 완료가 두 번 이상이면 「완료 N회」, 완료 한 번과 건너뜀이 있으면 「완료 · 건너뜀」이다. 접는 칸도 같은 글자를 쓴다.
- 블록 머리 줄의 굵은 제목은 종류 낱말만이다(「분기」「병렬」「반복」「재시도」). 이름은 입력 칸에만 있다. 선택 칸 `aria-label` 과 SFC 제목은 `flowBlockTitle` 그대로다(「분기 검사 결과」).
- 「병렬로 묶기」는 고른 줄을 갈래로 나눈다. 1개면 갈래 1 과 빈 갈래 2. 2~4개면 줄마다 한 갈래. 5개 이상이면 앞의 3개는 갈래 1~3, 나머지는 갈래 4에 순서대로. 실행 취소 한 번으로 돌아간다. 병렬 갈래 안의 병렬 · Substation 금지와 「같은 갈래에서 연속」은 그대로다.
- 4단계 안내 문구에 「병렬로 묶으면 고른 줄이 갈래마다 하나씩 나뉩니다」를 한 줄 넣었다.

정지 화면은 5공정 예제에서 단계를 비우고, 자재를 다루지 않는 CYL-01 전진과 S5 스토퍼 상승을 갈래로 나눈 뒤다. 스토퍼 완료 신호를 미발생으로 두고 그 단계 타임아웃을 0.2초로 한 다음 「끝까지」를 눌렀다. 실린더는 「정지」, 스토퍼는 「오류」다. 상태 줄은 `실행 error` 다.

## 하지 않은 것

- 6단계 화면, 3D, 오류 주입 칸, `RuntimePanel`
- `release/` 재빌드, 의존성 추가
- 이미 만들어진 흐름 예제 · 병렬 예제 블록

## 확인 필요

- 접는 칸 단계 표도 흐름 표와 같은 조합 글자(「완료 N회」, 「완료 · 건너뜀」)와 「진행 중」을 쓴다. 정지는 경고색 배지다.
- 고른 줄이 5개를 넘으면 갈래는 4개에서 멈추고, 나머지는 갈래 4에 순서대로 들어간다. 갈래 추가는 지금처럼 4개까지다.
- 로컬 `npm run typecheck` 와 `npm test` (45파일 551개) 는 통과했다. CI 판정은 이 기록이 아니다.
