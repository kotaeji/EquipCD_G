# TURN-050 물류 연결 끌어 잇기 · 우클릭 메뉴

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `README.md` · `release/` · `src/runtime/` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 바뀐 조작

1. 「선택/이동」에서 Unit 오른쪽 가운데 손잡이를 다른 Unit으로 끌면 물류 연결이 하나 생긴다. 모드를 바꾸지 않아도 된다. 끄는 동안 화살표가 따라오고, 놓을 수 있는 Unit만 강조된다.
2. 손잡이에서 시작한 끌기는 Unit을 옮기지 않는다. 몸체를 끄는 이동, 출력 포트를 입력 포트로 끄는 신호 연결, 오른쪽 아래 크기 손잡이는 그대로다. 도구 줄 「물류 연결」(두 번 누르기)도 남겨 두었다.
3. 자기 자신, 이미 있는 같은 방향, Unit이 아닌 곳에 놓으면 연결을 만들지 않고 까닭을 보여 준다. 빈 곳에 놓으면 아무 일도 없다. 한 번 잇기는 rev +1, Undo 한 번. 실행 중에는 시작하지 않는다.
4. 2단계 도면 도식 · 카드 보드와 탐색기 트리에서 우클릭(Shift+F10, 메뉴 키)하면 그 대상의 메뉴가 뜬다. 항목은 이미 있는 명령만 부르고, 단축키는 오른쪽에 적는다. 지금 못 하는 항목은 흐리고 툴팁에 까닭이 있다.
5. 삭제는 메뉴 맨 아래, 구분선 다음, `✕` 와 글자로 둔다. Unit · Device 삭제는 지금과 같은 영향 확인 창을 거친다. 연결만 지울 때는 지금처럼 확인 창 없이 지운다.
6. 고르지 않은 것을 우클릭하면 그것만 고르고, 여러 개 고른 것 중 하나를 우클릭하면 선택을 유지한다. Esc · 바깥 누름으로 닫히고, 방향키와 Enter로 고른다. 닫으면 초점이 돌아온다. 메뉴를 열고 닫기만 하면 rev · Undo가 그대로다.
7. 6단계 도면은 「화면 맞춤」과 「속성 보기」만 있다. 글자 입력 칸 위 우클릭은 브라우저 메뉴를 그대로 둔다.

## 한 일

- 물류 손잡이와 미리보기, 메뉴 위치 계산은 `src/ui/Canvas.tsx`, `src/ui/contextMenu.ts`, `src/ui/ContextMenu.tsx` 다. 연결은 기존 `addConnection` 만 쓴다.
- 도면 · 카드 보드 · 탐색기 트리가 같은 메뉴를 연다. 복사 · 붙여넣기 · 복제 · 정렬 · 자동 정렬 · 크기 맞춤 · 삭제는 도구 줄과 같은 함수다.
- Unit 위에 그려진 Device 위에 놓으면 그 Device의 Unit으로 잇는다. 자재 표식처럼 Unit도 Device도 아닌 곳은 거절한다.

## 확인 필요

- AC15는 Matthew 검수 전이다. 이 문서는 완료로 적지 않는다.
- Unit 안의 Device 위에 놓는 것을 그 Unit으로 잇는다. 「Unit이 아닌 곳」을 Device까지 포함해 거절해야 하면 되돌려 달라. 거절하면 유닛 대부분이 장치로 덮여 손잡이를 놓을 자리가 거의 없다.
- 6단계 「속성 보기」는 실행 화면 안에 읽기 전용 속성 칸을 연다. 2단계 「속성 열기」는 지금 있는 「속성 자세히」를 연다.
- 연결만 지울 때는 함께 빠지는 객체가 없어, 지금처럼 확인 창 없이 바로 지운다.
