# TURN-075 예제 갤러리 · 시작 마법사

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `README.md` 와 `release/` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

시작 화면의 예제 단추 세 개를 카드로 바꿨다. 카드에는 예제 이름, 한 줄 설명, 무엇을 보여 주는지, Unit · Device · 단계 수, 끝까지 걸리는 가상 시간, 「열기」가 있다. 수와 가상 시간은 `buildSampleProject` · `buildParallelSampleProject` · `buildFlowSampleProject` 에서 계산한다. 단계 수는 Station 단계와 Substation 단계의 합이고, 반복은 풀지 않는다. 가상 시간은 그 예제를 끝까지 실행한 시계다. 「열기」는 지금까지의 「예제 열기」「병렬 예제」「흐름 예제」와 같은 사본을 연다. 「5공정 예제로 둘러보기」는 그대로다.

「새 프로젝트」칸은 「빈 프로젝트 만들기」와 「뼈대부터」다. 빈 프로젝트는 지금처럼 1단계에서 열린다. 「뼈대부터」는 세 걸음이다.

1. 프로젝트 이름, Unit 수(1~8), Unit 이름. 기본 이름은 S1, S2, …
2. Unit 마다 빈 Unit, 번들 유닛 템플릿, 내 템플릿(이 브라우저에 있을 때).
3. 물류 연결을 순서대로 잇기(켜기 / 끄기)와 미리보기(Unit · Device · 연결 수).

「만들기」는 `addUnit`, `addUnitFromTemplate`, `placeUserTemplate`, `addConnection` 으로 프로젝트를 만든다. 시퀀스와 자재는 만들지 않는다. 만든 프로젝트는 저장되지 않은 상태이고, Unit 이 겹치지 않게 놓이며, 2단계 카드 보드에서 열린다. 실행 취소 기록은 비어 있다. 화면에는 「다음: 3단계에서 Action 을 확인하고 4단계에서 시퀀스를 만드세요」가 나온다. 어느 걸음에서 「취소」해도 프로젝트는 생기지 않는다. 「뒤로」를 눌러도 입력은 남는다.

Device 가 없는 Unit 만 있을 때 나오던 「Device가 없습니다」안내가 카드 옆 좁은 칸에 끼이지 않도록, 그 안내를 카드 줄 위로 올렸다.

아이콘은 TURN-061 뜻 표를 쓴다. 예제 카드는 예제 열기 · 병렬 예제 · 흐름 예제와 같은 아이콘이다. 「빈 프로젝트 만들기」는 새 프로젝트 아이콘이다. 「뼈대부터」는 표에 `starter`(Blocks)를 더했다.

## 화면 (1280×800)

Headless Chrome. 기기 픽셀 배율 1. 콘솔 오류 0. 문서 스크롤 0 (`scrollWidth` 1280, `scrollHeight` 800).

시작 화면의 가운데 칸은 카드 아래로 이어져 그 칸만 스크롤된다. 예제 카드 세 장과 「열기」는 첫 화면에 있다. 마법사 2걸음은 세 Unit 의 내용 선택이 한 화면에 있다. 만든 직후의 2단계는 안내와 카드가 보이고, 배치 칸은 약 57px 더 길다.

## 하지 않은 것

- 새 예제, 시퀀스 자동 생성, AI, 마법사에서 Device 낱개 고르기, 온라인 갤러리
- 명령 찾기 「새 프로젝트」와 탐색기 「+」의 「빈 프로젝트」. 둘은 지금처럼 빈 프로젝트를 바로 만든다
- `README.md`, `release/` 재빌드, 의존성 추가

## 확인 필요

- 처음 쓰는 사람이 뼈대를 만들 수 있는가(AC9)는 사람 검수다. 이 문서는 완료로 적지 않는다.
- 명령 찾기와 「+」메뉴의 빈 프로젝트는 마법사로 들어가지 않는다. 시작 화면만 「뼈대부터」를 둔다.
