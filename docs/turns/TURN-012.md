# TURN-012 도면 포트 연결 — 눌러도 안 움직이고, 끌어서 잇기

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 바뀐 조작

1. 출력 포트를 다른 장치의 입력 포트로 끌면, 모드와 상관없이 신호 연결이 하나 생긴다. 끄는 동안 임시 선이 보이고, 이을 수 있는 입력 포트는 강조된다.
2. 포트를 누르거나 조금 흔들어도 장치는 움직이지 않는다. 장치 이동은 몸체를 끌 때만 된다. 「신호 연결」 모드의 두 번 누르기는 그대로다.
3. 카드 보드에서 「신호 연결」 모드로 Unit 카드를 눌러도 물류 연결은 생기지 않는다. 「물류 연결」 모드의 도면에서 Device를 누르면 그 Device가 속한 Unit으로 잇는다.

## 한 일

- 포트의 누르는 영역은 16×16px이고, 보이는 점은 약 10px이다. 포트·신호선 레이어가 켜져 있으면 모든 모드에서 포트가 눌린다.
- 끌어서 잇기와 두 번 누르기 모두 기존 `addConnection` 으로만 모델에 반영된다. 연결 하나의 rev +1, Undo 한 번으로 사라진다.
- 입력 포트에서 시작하면 첫 동작에서 「출력(out) 포트에서 시작하세요」. 같은 Device, 중복, 빈 곳에 놓기, Esc 는 연결을 만들지 않는다.
- 실행 중에는 끌어서 잇기를 시작하지 않고, 모델 편집 차단 문구를 보여 준다.
- 「연결 시작」 안내는 `PSH-01 푸셔 · pushDone (출력)` 처럼 장치 이름, 신호 이름, 방향이다.

## 화면 (1280×800, 5공정 예제, 도면 도식)

Chrome으로 개발 서버를 열어 찍었다. 확대는 약 115%다. 맞추기 기본값(50%)에서는 선이 너무 작아 끄는 동작이 보이지 않았다.

- 출력 포트에서 끄는 중, 라이트: `TURN-012-drag-light-1280.png`
- 출력 포트에서 끄는 중, 다크: `TURN-012-drag-dark-1280.png`
- 연결 완료 뒤, 라이트 (rev 2, Undo 1): `TURN-012-connected-light-1280.png`

## 하지 않은 것

- 물류 연결의 끌어서 잇기, 연결선 다시 잇기, 연결선 위 Delete 키
- `addConnection` 의 허용·거부 조건
- 배경 도면, 잠금, 서브플로
- 의존성 추가, `release/` 재빌드
- `docs/FEATURE-LIST.md`, 사용자 매뉴얼, 와이어프레임

## 확인 필요

- AC12는 Matthew 검수 전이다. 이 문서는 완료로 적지 않는다.
- 16px는 포트 요소의 크기이다. 도면이 50%로 맞춰지면 화면에서 차지하는 픽셀은 그보다 작다.
- 매뉴얼 6.3절과 기능 목록의 「핸들을 끌어 연결하기」는 머지 뒤 루카가 맞춘다.
