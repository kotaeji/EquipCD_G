# TURN-045 위험 단추 구분 · 숫자 칸 단위와 오류 · 대비 자동 검사

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `README.md` · `release/` · `src/runtime/` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

지우기 단추는 붉은 외곽선과 `✕` 기호와 글자를 함께 쓴다. 2단계 도면 도구 줄과 속성 칸에서는 그 줄의 오른쪽 끝에 둔다. 6단계 「⟲ 초기화」는 실행 기록만 지우므로 이 모양이 아니다.

시퀀스에서 쓰는 Action, 조건에서 쓰는 Signal, 단계가 가리키는 Position, 흐름에 들어 있는 시퀀스 단계는 단추 옆에 쓰임 수를 보여 주고, 확인 창의 처음 초점은 「취소」다. Enter 만으로는 지워지지 않는다. 쓰임이 없으면 지금처럼 바로 지운다.

숫자 칸은 단위를 칸 안 오른쪽에 둔다. 숫자가 아닌 값, 음수, 개수(`ea`)의 소수는 오류 테두리와 한 줄 까닭만 보이고 모델에 넣지 않는다. 빈 칸은 미정이다. 「미정」·「가정」은 TURN-039 표시를 칸 옆에 그대로 둔다.

라이트·다크의 본문·흐린 글자·단추·강조·위험·경고·성공·테두리·도면 점·고른 항목 글자를 테스트로 잰다. 글자는 4.5:1, 선은 3:1. 모자란 테두리와 도면 점만 올렸다. 헤더 빨강과 TURN-039 상태 색은 그대로다.

## 확인 필요

- 사용 중인 Action 을 확인 후 지우면, 그 Action 을 쓰는 Station·Substation 단계도 함께 빠진다. 이전 명령은 삭제를 거절했다. 단계를 남기면 참조가 깨져 실행이 멈춘다. 이 변경을 삭제 규칙 변경으로 보면 되돌려 달라.
- 사용 중인 Signal 은 거절 대신 명령·완료·조건을 풀고 신호와 그 연결을 지운다. Position 은 목표 참조만 `null` 로 푼 뒤 지운다.
- 덮어쓰기 단추는 화면에 없다. 단계 타임아웃 덮어쓰기는 숫자 칸이다.
- 연결만 지울 때는 함께 빠지는 다른 객체가 없어 확인 창 없이 바로 지운다.
