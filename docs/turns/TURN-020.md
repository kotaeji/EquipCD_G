# TURN-020 공통 탐색 검색 · 안내 화면 「준비 중」 표시

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `README.md` 는 동시 진행 규칙에 따라 고치지 않았다. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

공통 탐색(`SearchSheet`)의 트리 위에 검색 입력을 넣었다. `type="search"`, 레이블 「이름으로 찾기」. 검색어는 이 화면의 state 다. 모델, rev, 선택, 저장되는 보기 설정은 바꾸지 않는다. `SearchSheet` 의 props 는 그대로다.

이름 비교는 대소문자를 가리지 않고 앞뒤 공백만 뺀다. 이름에 그 글자가 든 항목과, 그보다 얕은 윗단계만 남긴다. 걸린 항목의 자식은 이름에 걸리지 않으면 빼 둔다. 검색어가 있으면 `2개 찾음` 처럼 걸린 수를 보인다. 없으면 「찾는 이름이 없습니다」와 「지우기」가 나오고, 지우면 전체 트리로 돌아온다. 항목을 누르면 이전과 같이 `onPick` 이다.

자료 입력, Workspace 파일 묶음, Evolution Lab, 누락 편집 확장의 맨 위에 같은 알림 줄(`NotReadyBanner`, `role="note"`)을 붙였다. 첫 줄은 「준비 중 — 이 화면은 아직 동작하지 않습니다」. 그 화면에서 지금 대신 쓸 곳을 한 줄 더 적었다.

| 화면 | 대신 쓸 곳 |
|---|---|
| 자료 입력 | 입력 후보표의 직접 입력과 AML 라이브러리를 쓰세요 |
| Workspace 파일 묶음 | 프로젝트별 JSON 내보내기를 쓰세요 |
| Evolution Lab | Gap 목록의 가정 시간 합계를 쓰세요 |
| 누락 편집 확장 | Station 단계 시간은 4단계 Station 시퀀스에서 편집하세요 |

자료 입력 문장은 Issue 의 예시다. Lab 과 누락 편집은 기존 안내(`LabPanel`, `ExtendPanel`)에 적힌 대신 쓸 곳을 명령형으로 줄였다. 파일 묶음은 Workspace 탭 안내의 「옮기려면 프로젝트별 JSON 내보내기」를 같은 형식으로 줄였다. 기존 비활성 단추와 문구는 그대로다. 스타일은 `src/ui/sparse-extra.css` 이고 `styles.css` 는 건드리지 않았다. 글자색은 `var(--text)`, 바탕은 `var(--panel)` 이다. 왼쪽 경고색 테두리는 보조이고, 뜻은 글자에 있다.

## 화면 (1280×800)

Chrome 157.0.8103.50, CSS 뷰포트 1280×800, devicePixelRatio 1. 콘솔 오류 0. 공통 탐색은 검색어 `  cYL  ` 가 들어간 상태다. 트리는 S1 투입, CYL-01, S3 가공, CYL-03 만 남고 `2개 찾음` 이다. rev 는 1 그대로다. 다크로 바꿔도 검색어는 남는다. 없는 이름을 넣고 「지우기」를 누르면 트리 15개가 돌아온다.

알림 줄 글자와 그 뒤 패널 바탕의 대비(WCAG):

| 테마 | 글자 | 바탕 | 대비 |
|---|---|---|---|
| 라이트 | `rgb(23, 40, 63)` `#17283F` | `rgb(255, 255, 255)` `#FFFFFF` | 14.88:1 |
| 다크 | `rgb(239, 245, 253)` `#EFF5FD` | `rgb(25, 40, 58)` `#19283A` | 13.62:1 |

제목은 굵기 700, 대신 쓸 곳 한 줄은 400, 둘 다 14px 이다. 두 테마 모두 4.5:1 보다 높다. 검색 입력은 시트 안에서 끝난다(오른쪽 868px, 시트 880px). 가로 스크롤은 없다. 알림 줄과 바로 아래 시트 사이는 12px 이고 겹치지 않는다. Evolution Lab 의 본문은 알림 줄 높이만큼 길어져 아래 접는 칸은 그 영역 안에서 스크롤된다(client 480px, scroll 661px). 알림 줄 자체는 뷰포트 안에 다 들어온다.

## 확인 필요

- AC10 은 Matthew 검수 전이다. 이 문서는 완료로 적지 않는다. 공통 탐색에서 이름으로 바로 찾을 수 있는지, 준비 중인 화면이 한눈에 구별되는지는 사람 검수다.
- 파일 묶음의 대신 쓸 곳 문장은 Workspace 탭에 이미 있는 「프로젝트별 JSON 내보내기」를 옮긴 것이다. 그 줄을 빼야 하면 알려 달라.
- `App.tsx` 가 `SearchSheet` 에 넘기는 트리는 Unit(depth 0)과 Device(depth 1)뿐이다. Station 행은 없다. 필터는 더 얕은 행을 윗단계로 남기므로, Station 행이 트리에 있으면 함께 남긴다. 이번 화면의 검색 결과에는 Station 이름이 나오지 않는다. `App.tsx` 는 맡는 파일이 아니라서 트리를 늘리지 않았다.
