# TURN-035 6단계 통일(가운데만 도면 / 3D) · 진행 중 강조 · 탐색기 접기

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.3.1`. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

6단계 「도면」과 「3D」가 같은 틀이다. 「도면 / 3D」는 가운데 캔버스만 바꾼다. 실행, 선택, 칸 접힘은 전환해도 유지된다.

- 가운데 위 **요약 띠**. 실행 상태 · 가상 시간 · 실행 중 단계 · 자재가 한 줄이고, 사이클 시간 · 시간당 생산량(가정) · 병목 Unit · Gap 이 다음 줄이다. 프로젝트 이름과 Unit · Device · 단계 수는 띠 앞에 작게 있다. 「접기」는 실행 상태 · 가상 시간 · 실행 중 단계만 남기고, 그 접힘은 이 브라우저에 남는다.
- 왼쪽 **단계**. 단계별 시간 · Unit 별 합계 · 선택한 Device. 단계 줄에 갈래 · 회차가 있다.
- 오른쪽 **가동 조건**. 도면과 3D가 같이 쓴다. 배속 · 표시 옵션 · 준비 검사 · 동작 시간 · 타임아웃 · 오류 주입 · 되돌리기 순이다. 이름 표시 · 동작 강조 · 설비 동작은 도면일 때 꺼진 채이고, 이유는 「3D 보기에서 쓰는 옵션입니다」다. 3D에서는 「설비 동작」이 켜져 있고, `Scene3D`에 움직임과 실행 중 여부를 넘긴다.
- 가운데 아래 **자세히**. 기본은 접혀 있고, 머리 줄에 최근 로그 한 줄이 있다. 펼치면 실행 결과 요약 · 실행 로그 · 신호 탭이다. 펼침과 고른 탭은 이 브라우저에 남는다.
- TURN-030 탭(실행 상태 / 실행 도면 / 검사 · 오류 주입)과 `runTab` 기억 값은 없다.
- 실행 칸 너비 조절 막대는 없다. 오른쪽은 가동 조건 접기로 좁힌다.

진행 중인 단계 줄은 옅은 바탕(`--selected`)과 2px 강조색 테두리, 굵은 글자다. 병렬이면 여러 줄이 같이 그렇다. 오류 줄은 위험색, 정지 줄은 경고색 테두리다. 같은 클래스를 자세히의 요약 표와 4단계 흐름 표에도 쓴다. 진행 중인 줄이 목록 밖이면 보이는 자리로 스크롤하고, 목록을 직접 스크롤한 뒤 3초 동안은 건드리지 않는다.

탐색기 접기는 40px 레일이 되고 작업 영역이 그만큼 넓어진다. 1280에서 작업 영역은 1056px에서 1240px이 된다. 1600px 이상에서도 접힌 폭은 40px이다. 접힘은 이 브라우저에 남고, 레일 단추는 `aria-label`과 `aria-expanded`를 갖는다.

## 도면에 있던 것의 새 자리

| 도면 보기에 있던 것 | 새 자리 |
|---|---|
| 단계 표의 갈래 · 회차 | 왼쪽 단계 줄 |
| 단계 표의 자재 위치 | 요약 띠 「자재」 |
| 실행 결과 요약 표 | 「자세히」 › 실행 결과 요약 |
| 현재 단계 · 신호 상태 | 요약 띠(실행 중 단계) · 「자세히」 › 신호 |
| 자세한 로그 표, 오른쪽 「실행 로그」(최근 8줄) | 「자세히」 › 실행 로그(전체) + 접힌 머리 줄의 최근 한 줄 |
| 준비 검사 · 차단 목록 · 이동 단추 | 오른쪽 가동 조건 |
| 오류 주입(읽기 실패 · 완료 신호 미발생) | 오른쪽 가동 조건 |
| 실행 차단 안내(`BlockerSheet`) | 가운데 캔버스 위 |
| 오른쪽 칸의 「저장」 단추 | 위 단추 줄의 「저장」 |
| 실행 칸 너비 조절 | 오른쪽 가동 조건 접기. 폭 조절 막대는 없앰 |
