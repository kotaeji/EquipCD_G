# TURN-053 명령 찾기(Ctrl/Cmd+K) · 단축키 목록(?)

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `README.md` · `release/` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 바뀐 조작

1. 어느 단계에서든 Ctrl+K 또는 Cmd+K 로 가운데 위에 명령 찾기가 열린다. 헤더 「명령 찾기」도 같은 창을 연다. 글자로 이름을 거르고, ↑↓ 로 고르고, Enter 로 실행하고, Esc 로 닫는다. 닫으면 초점이 돌아온다.
2. 입력 칸 밖에서 `?` 를 누르면 단축키 목록이 열린다. 명령 찾기에서 「단축키 목록」을 골라도 열린다. Esc 와 「닫기」로 닫힌다. 입력 칸 안에서는 `?` 가 글자로 들어간다. Ctrl/Cmd+K 는 입력 칸에서도 연다.
3. 줄에는 명령 이름, 묶음, 단축키가 있다. 지금 못 하는 명령은 흐리고 까닭이 보이며 Enter 로 실행되지 않는다. 다른 단계의 명령을 고르면 그 단계로 옮긴 뒤 실행한다. 글자 없이 열면 지금 단계에서 쓸 수 있는 명령이 먼저 나온다.
4. 여는 것·닫는 것만으로는 rev · Undo 가 바뀌지 않는다. 확인 창이나 둘러보기가 떠 있으면 열리지 않는다.

## 한 일

- 명령 이름 · 묶음 · 단축키 · 가능 여부 · 실행은 `src/ui/commandModel.ts` 한 파일이다. 복사 · 붙여넣기 · 복제 · 정렬 · 자동 정렬 · 실행 잠금은 우클릭 메뉴와 같은 판정과 문구를 쓴다. 키 처리도 이 파일의 `commandForEvent` 를 탄다.
- 창은 `src/ui/CommandPalette.tsx` 다. `styles.css` 는 파일 끝에 토큰(`--fs-*` · `--sp-*`)만 더했다.
- 시퀀스 줄 선택은 `FlowEditor` 가 그대로 두고, 고른 줄만 앱이 기억한다. 그래서 6단계에서 「병렬로 묶기」는 고른 줄이 없으면 흐리고, 있으면 4단계로 가서 묶는다.

## 확인 필요

- AC13은 Matthew 검수 전이다. 이 문서는 완료로 적지 않는다.
- 명령 이름은 단추 글자를 따랐다. 「▶ 실행」「❚❚ 일시정지」「⟲ 초기화」의 장식 기호는 빼고 「실행」「일시정지」「초기화」로 두었다. 헤더 단추 「내보내기」는 범위에 적힌 「JSON 내보내기」다. 실행 화면 단추 「3D」는 「3D 보기」다.
- 「둘러보기」는 지금 단추와 같이, 한 번도 안 봤으면 「5공정 예제로 둘러보기」, 그 다음부터 「둘러보기 다시 보기」다. 「탐색기」는 열려 있으면 「탐색기 접기」, 접혀 있으면 「탐색기 펼치기」다.
