## 한 일

2단계 도면 도식과 6단계 도면에서, 초점이 도면 안에 있을 때 마우스 없이 Unit · Device 를 고르고, 옮기고, 잇는다.

- Tab / Shift+Tab 은 Unit 을 읽기 순서로 돈다. Enter 는 그 Unit 의 Device 로 들어가고, Esc 는 한 겹 나온다. 상태 줄은 `S2 식별 › BCR-02` 처럼 지금 위치를 읽고, `aria-live` 로 알린다. 고른 칸은 TURN-077 과 같은 2px `--focus` 링이다.
- 방향키는 10, Shift+방향키는 50, Alt+방향키는 1 이다. 키를 누르고 있는 동안과 뗀 뒤 0.5초 안의 이동은 편집 하나다. rev 는 1 오르고 Undo 한 번으로 돌아온다. 옮기는 동안 상태 줄에 좌표가 보인다.
- 잠긴 Unit 은 움직이지 않고 「위치 잠금된 Unit은 움직이지 않습니다」가 나온다. Device 중심이 다른 Unit 안으로 들어가면 끌기와 같은 소속 변경 창이 열린다.
- `L` 은 물류, `S` 는 그 Device 의 첫 출력 포트에서 신호를 잇기 시작한다. Tab 으로 대상을 고르고 Enter 로 확정한다. 거부 문구는 `addConnection` 그대로다. Esc 는 잇기를 취소한다.
- `+` / `-` 는 확대 · 축소, `0` 은 화면 맞춤이다. 고른 것이 창 밖이면 그쪽으로 화면이 움직인다.
- 글자 입력 칸에서는 동작하지 않는다. Ctrl+A · Delete · Ctrl+C/V/D 는 그대로다. 실행 중에는 순회와 보기만 되고 옮기기 · 잇기는 막힌다.
- 단축키 목록과 2단계 도면 도움말에 새 키를 넣었다.
