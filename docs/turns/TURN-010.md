# TURN-010 Project 탭 — 짧은 프로젝트 목록 · 트리 위로 · 상세 팝업

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식 `0.2.0` 과 실행 규칙은 바꾸지 않았다. `release/` 는 다시 빌드해 커밋하지 않았다. CI 확인 대기 — 통과 판정은 Actions를 따른다. AC10은 Matthew 검수 전이다.

## 한 일

1. Project 탭 순서를 `Workspace: 이름` → `프로젝트 (N)` 목록 → 장비 구조로 바꿨다. 저장 목록 표, 설명 문단, 새 프로젝트 3버튼 줄, JSON 가져오기·프로젝트 파일 버튼 줄, 줄의 ✎·× 는 탭에서 뺐다.
2. 목록은 열린 탭(탭 순서) 다음에, 이 Workspace의 저장 프로젝트 중 아직 열리지 않은 것(최근 저장 순)을 붙인다. 같은 ID는 한 줄이다. 편집 중은 `.exitem.on`, 열려 있고 편집 중이 아니면 작은 점, 미저장은 `●` (`var(--warning)`). 줄을 누르면 열린 프로젝트는 전환하고, 닫힌 저장 프로젝트는 연다.
3. 목록은 최대 6줄(168px)이고, 7번째부터는 그 칸만 스크롤한다.
4. `+` 메뉴에 빈 프로젝트, 5공정 예제, 병렬 예제, JSON 가져오기, 프로젝트 파일을 넣었다.
5. `…` 는 기존 Overlay 모양의 팝업이다. 제목은 `프로젝트 — 이름`. 이름, ID, 상태(편집 중 / 열림 / 닫힘), 저장 상태, 소속 Workspace를 보여주고, 열기 또는 전환, 이름 변경, 탭 닫기, 삭제를 둔다. 비활성 이유는 `title` 이다. Esc와 「닫기」는 팝업만 닫고 포커스는 그 줄의 `…` 로 돌아간다.
6. 저장소를 쓸 수 없으면 목록은 열린 프로젝트만 두고, 팝업의 저장 줄은 「브라우저 저장소 사용 불가」다.

## 옮긴 동작

| 원래 위치 | 새 위치 |
|---|---|
| `Workspace: 이름` | 그대로. 누르면 Workspace 탭 |
| 열린 프로젝트 줄 클릭 | 프로젝트 목록 줄 클릭 → 전환 |
| 줄의 `● 미저장` | 같은 줄의 `●` (`aria-label` 미저장) |
| 줄의 ✎ | 팝업 「이름 변경」. 열린 프로젝트는 모델 변경(rev +1, Undo) |
| 줄의 × | 팝업 「탭 닫기」. 저장 데이터는 지우지 않음 |
| 「+ 빈 프로젝트」·「+ 5공정 예제」·「+ 병렬 예제」 | `+` 메뉴 |
| 「JSON 가져오기」·「프로젝트 파일」 | `+` 메뉴. 작업 시작 화면의 JSON 가져오기는 그대로 |
| 저장된 프로젝트 표의 열기 / 탭으로 이동 | 줄 클릭, 또는 팝업 「열기」/「이 프로젝트로 전환」 |
| 닫힌 저장 프로젝트 이름 변경 | 팝업 「이름 변경」 (`renameSaved`, rev +1, Undo 아님) |
| 닫힌 저장 프로젝트 삭제 | 팝업 「삭제」. 확인 창은 이전과 같음. 열린 프로젝트는 비활성 |
| 설명 문단의 탭 닫기·저장 소속 안내 | 팝업 아래 작은 글씨 |
| 저장소 불가 안내 | 팝업의 저장 상태 줄 |
| 장비 구조, 모두 펼치기·접기, Station 줄, 트리, 선택 안내 | 목록 아래. 그대로 |

작업 시작 화면의 「프로젝트 관리」는 Project 탭을 여는 지금 동작 그대로다.

## 하지 않은 것

- Workspace 탭, 위쪽 작업 정보 줄, 작업 시작 화면
- 저장 형식, 저장소 키, 열기·닫기·이름 변경·삭제 규칙
- 트리 꺾쇠 그림, 팔레트, 실행 툴바
- 의존성 추가, `release/` 재빌드
- 사용자 매뉴얼. 아직 ✎·× 와 저장 목록으로 적혀 있다
