# TURN-070 확인 이력 — 누가 · 언제 확인했는지

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 프로젝트 파일 형식은 `0.3.0` 그대로다. Export 초안 형식은 `0.1.0` 그대로다. `README.md` 는 고치지 않았다. `release/` 는 다시 빌드해 커밋하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

확인자 이름은 「보기 설정」에 둔다. 이 브라우저에만 기억하고, 프로젝트 파일에는 설정으로 넣지 않는다. 이름이 비어 있으면 처음 확인할 때 한 번 묻는다. 로그인이나 인증은 없고, 적은 글자를 그대로 남긴다는 안내와 함께, 그 이름이 프로젝트 파일의 확인 이력에 들어간다고 적는다. 이름은 60자까지다.

다음을 바꿀 때 이름 · 시각(ISO) · 대상 이름 · 이전 상태 → 새 상태를 프로젝트에 남긴다. 확인을 되돌릴 때도 한 줄을 더한다.

- 수치의 가정 ↔ 확인 (Device 속성, Action 동작 시간 · 타임아웃, Position, Unit 수용, 자재, 단계 타임아웃)
- Interlock 확인, 그리고 확인됨에서 벗어남
- 입력 후보 확인 / 거절, 그리고 그 상태에서 벗어남
- Gap 「사람 확인」, 그리고 사람 확인에서 벗어남
- 신호 주소 확인, 그리고 확인에서 벗어남

한 번의 확인은 rev +1 이고 Undo 한 번이다. 실행 취소하면 이력 줄도 사라지고, 다시 실행하면 돌아온다.

이력은 프로젝트의 선택 필드다. 비어 있으면 파일에 쓰지 않는다. 형식 버전은 올리지 않는다. 이력 없는 예전 파일은 그대로 읽힌다. 예제 3종의 저장 결과에는 `confirmationLog` 가 없다.

5단계 「진단·저장」에 「확인 이력」 표가 있다. 칸은 시각 · 확인자 · 대상 · 바뀐 내용이고, 줄은 시각순이다. 「이동」은 그 대상으로 간다. 대상이 지워졌으면 「삭제됨」이다. 속성 칸에서 아직 확인 상태인 값 옆에는 「확인: 이름 · 날짜」가 붙는다.

Export 초안(TURN-041)은 이력이 있을 때만 `confirmationLog` 를 넣는다. 역매핑 검사에 그 줄이 들어간다. 이력이 없는 예제 초안에는 그 필드와 `"at"` 가 없다.

`tests/ui-turn046.test.tsx` 는 Interlock 「확인」 뒤에 이름을 넣고 이어 간다. 막힘 동작은 그대로다.

## 화면 (1280×800)

Chrome, CSS 뷰포트 1280×800, devicePixelRatio 1. 콘솔 오류 0. 5공정 예제. 가정 체크를 끄면 이름 창이 뜨고, 이름을 넣은 뒤 Interlock 을 확인하면 진단·저장의 표에 두 줄이 시각순으로 나온다. 다크로 바꿔도 같은 내용이다.

- 확인자 이름 창, 라이트: `TURN-070-ask-light-1280.png`
- 확인자 이름 창, 다크: `TURN-070-ask-dark-1280.png`
- 확인 이력 표, 라이트: `TURN-070-log-light-1280.png`
- 확인 이력 표, 다크: `TURN-070-log-dark-1280.png`

## 하지 않은 것

- 로그인 · 전자 서명 · 권한 · 승인 절차
- 확인 말고 다른 편집의 이력
- `README.md`, `release/`, 의존성 추가, `styles.css` 에 새 규칙 추가

## main 합침

TURN-061 · 062 · 065 · 066 이 들어간 `origin/main` 을 merge 했다. rebase 는 하지 않았다. `tests/turn054.test.ts` 는 main 그대로다. 새 단추는 뜻 표의 `confirm`(확인) · `jump`(이동) · `undo`(되돌림) · `close`(취소) 를 쓴다.

## 확인 필요

- AC9는 Matthew 검수 전이다. 이 표가 검토 회의에서 쓸 만한지는 사람 검수다.
- 스탬프 없이 모델을 직접 바꾸는 예전 호출은 상태를 바꾸되 이력 줄을 만들지 않는다. 화면의 확인은 항상 이름을 남긴다.
- 확인된 주소 글자를 비우면 상태는 미지정이 된다. 그 경로에는 되돌림 줄을 넣지 않는다. 「되돌림」 단추가 줄을 남긴다.
- 사람 확인된 Gap 을 「숨김」으로 바꾸면 확인을 되돌린 줄이 되고, rev 와 Undo 가 하나 늘어난다. 확인되지 않은 Gap 의 숨김은 예전처럼 실행 취소 대상이 아니다.
