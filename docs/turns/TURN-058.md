# TURN-058 Evolution Lab 1차 — 가동 조건 What-if 비교

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.6.0` 그대로다. `release/` 는 다시 빌드하지 않았다. `README.md` 는 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

5단계 Evolution Lab 에서 기준(지금 모델)과 변형 안 1~3개(합쳐 4안)의 가동 조건만 바꿔 끝까지 계산하고, 한 표로 비교한다. 5번째 안은 만들 수 없다.

안마다 이름과 바꿀 숫자를 고른다. Action 동작 시간(Action 하나, 또는 모든 Action × 배율), Action 타임아웃, 투입 개수, 투입 간격. 구조는 바꾸지 않는다.

「모두 실행」은 안마다 모델 사본에 값을 넣어 6단계 「끝까지」와 같은 엔진으로 계산한다. 열린 모델과 6단계 실행 상태는 건드리지 않는다. 안을 만들고 고치는 것도 rev · Undo 를 바꾸지 않는다.

비교 표의 안은 열, 지표는 행이다. 끝남 / 오류 코드, 총 가상 시간, 사이클, 시간당 생산량, 병목, 가장 긴 단계, 기준 대비 차이(시간 · %). 개체 3개 이상이면 사이클에 「정상 상태(가정)」, 그보다 적으면 「한 개 기준」이 붙는다. 숫자는 실행 결과 요약 · `steadyCycleMs` · 실행 화면의 병목과 같다. 가장 짧은 시간 · 가장 큰 생산량에만 표시하고, 추천이라고 쓰지 않는다. 실행 전 검사에 걸린 안은 「실행 불가 — 까닭」이고 나머지는 계속 계산된다. 결과에는 계산한 모델 rev 가 있고, 모델이 바뀌면 「이전 rev 의 결과」가 붙는다.

「모델에 반영」은 바뀌는 값(무엇이 얼마에서 얼마로)을 확인 창으로 보여 주고, 확인하면 rev +1 · Undo 한 번이다. 실행 중 · 일시정지 중에는 막힌다. 동작 시간 · 타임아웃 · 투입 간격의 근거는 `Evolution Lab 안 〈이름〉에서` 이고 상태는 가정이다. 투입 개수는 Quantity 가 아니라서 같은 문장을 `assumptionsNote` 에 남긴다.

안은 열린 탭에만 있다. 화면을 나갔다가 돌아와도 남고, 프로젝트 파일에는 들어가지 않는다. 화면 위 한 줄은 「논리 시뮬레이션 비교입니다. 자동 탐색 · 최적화 · AI 는 쓰지 않습니다.」 안이 없으면 「변형 안이 없습니다」와 「안 추가」다. 「준비 중」 표시는 이 화면에서 뺐다.

5공정 예제에서 기준 총 시간은 `00:11.100` 이다. 가공 실린더를 1초로 줄이면 `00:10.100`(−9.0%)이다. 모든 동작 시간 × 0.5 는 `00:05.550`(−50.0%)이다. 투입 5 · 간격 0 은 총 시간 `00:29.100`, 정상 상태 사이클 `00:04.500`, 시간당 생산량 `800.0`, 병목 S2 식별 `00:13.100` 이다.

## 확인 필요

- 비교 표만 보고 어느 안이 왜 빠른지 읽히는가는 사람 검수(AC13)다. 이 문서는 완료로 적지 않는다.
- 병목 칸은 실행 화면과 같다. 기다린 시간 합이 있으면 그 시간이고, 없으면 한 개 기준으로 가장 오래 걸린 Unit 시간이다.
- 투입 개수에는 가정 플래그가 없다. 반영 근거는 `assumptionsNote` 한 줄이다. 동작 시간 · 타임아웃 · 투입 간격은 Quantity 의 `source.note` 와 가정이다.
- 이 화면의 「준비 중」을 빼면서 `tests/ui-turn020.test.tsx` · `tests/ui-turn051.test.tsx` 의 Lab 항목만 갱신했다. 자료 입력 · 묶음 · 누락 편집 확장은 그대로다.
- `README.md` 의 「안 된 것」은 이슈에서 고치지 말라고 해서 그대로다. F7 전체가 아직 미구현으로 적혀 있다.
