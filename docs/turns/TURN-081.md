# TURN-081 저장본과 지금의 차이 보기

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. `README.md` 와 `release/` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

5단계 「진단·저장·AML」 맨 위에 「바뀐 것」을 두었다. 기본은 저장본과 지금이다. 요약은 `추가 a · 삭제 b · 바뀜 c` 이고, 종류별로 접는다. 바뀐 줄은 항목과 전 → 후를 보여 준다. 차이가 없으면 「저장본과 같습니다」. 저장하면 그 목록은 비운다. 한 번도 저장하지 않았으면 「저장본이 없습니다」.

비교는 `diffProjects` 한 함수다. 모델을 바꾸지 않고, rev 와 Undo 도 바꾸지 않는다. ID 로 짝을 맞춘다. 도면에서 옮긴 x, y, 너비, 높이는 「위치」 한 줄이다. 줄의 「이동」은 지금 모델에 있는 대상으로 가고, 삭제된 줄에는 이동이 없다.

같은 화면에서 이 Workspace의 다른 저장 프로젝트나 JSON 파일을 고를 수 있다. 파일은 지금의 가져오기 검사를 통과한 뒤에만 비교한다. 깨진 파일은 거절하고 모델을 그대로 둔다. 합치지는 않는다.

복구 창에 「차이 보기」를 두었다. 복구하거나 버리기 전에, 임시 저장과 저장본의 차이를 본다. 앞은 저장본, 뒤는 임시 저장이다. 이 목록에는 이동을 두지 않는다. 임시 저장은 아직 열린 모델이 아니다.

## 화면

Headless Chrome. 1280×800. 기기 픽셀 배율 1. 콘솔 오류 0. 문서 스크롤 0 (`scrollWidth` 1280, `scrollHeight` 800).

저장한 뒤 CNV-05 를 지우고, S1 푸셔 투입 동작 시간을 0.8 s 에서 9.5 s 로 바꿨다. 추가 0 · 삭제 5 · 바뀜 3. 지운 Device 에는 이동이 없고, 동작 시간 줄의 이동은 그 Action 으로 간다. rev 3, Undo 2.

## 하지 않은 것

- 합치기, 줄 단위로 되돌리기, 여러 저장 버전 이력, 글자 단위 차이
- `README.md`, `release/` 재빌드, 의존성 추가
- `styles.css` 에 새 규칙. 스타일은 `project-diff.css`
- `tests/turn054.test.ts` 수정

## 확인 필요

- 라이브러리에서 Device 를 더하면 그 Device 와 함께 생기는 신호·Action, 그리고 Unit 의 장치 목록도 각각 한 줄이다. AC1 의 추가 1 · 삭제 1 · 바뀜 1 은 그 세 가지만 다른 모델이다.
- 위치 잠금은 양쪽 다 있는 Unit 에서 풀림과 잠김이 다를 때 「잠금」 한 줄이다. rev 숫자는 차이 줄로 세지 않는다.
- 복구 창의 차이 목록은 길면 목록만 스크롤하고, 복구와 버리기는 그 아래에 둔다.
- 저장 전에 훑어보기에 쓸 만한가(AC10)는 사람 검수다. 이 문서는 완료로 적지 않는다.
