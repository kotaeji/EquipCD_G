# TURN-069 헤더 정리 · 도움말 칸이 화면을 좁히지 않게

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.6.0`. `README.md` 와 `release/` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

1. **헤더** — 저장 · 실행 취소 · 다시 실행 · 명령 찾기는 어느 폭에서나 헤더에 남는다. 1440 이상에서는 내보내기 · 보기 설정 · 도움말 · 실행 취소 이력도 글자와 함께 보인다. 1280 이상 1440 미만에서는 한 줄에 다 들어가면 그대로 두고, 넘치면 덜 쓰는 것(실행 취소 이력, 그다음 도움말, 그다음 보기 설정, 그다음 내보내기)부터 「더 보기」로 넣는다. 1280 미만(1024 포함)에서는 그 넷을 항상 「더 보기」에 둔다. 메뉴는 TURN-050 의 명령 메뉴다. 방향키 · Enter · Esc, 닫으면 초점이 「더 보기」로 돌아온다. 항목 이름 · 아이콘 · 동작은 원래 단추와 같다. 실행 취소 이력의 아이콘은 뜻 표의 `undo-history`다. 단추의 접근성 이름과 글자는 바꾸지 않았다.
2. **작업 줄** — 프로젝트 이름과 Workspace 이름은 길면 줄임(…)이고, 마우스를 올리면 전체가 나온다. rev 와 「저장 안 됨」은 줄지 않는다.
3. **도움말** — 1440 이상에서는 지금처럼 오른쪽에 나란히 선다. 1440 미만에서는 320px 칸이 작업 칸 위에 겹친다. 가운데 칸의 너비는 그대로다. 머리 줄을 끌면 놓는 쪽이 화면의 왼쪽 또는 오른쪽 가장자리에 붙는다. 「접기」는 머리 줄만 남기고, 다시 「펼치기」로 연다. Esc 로 닫히고, 가려지지 않은 화면은 그대로 누를 수 있다. 옮긴 쪽과 접힘은 이 브라우저의 보기 설정에 남는다. 도움말 글과 용어 풀이는 바꾸지 않았다.

「더 보기」의 아이콘은 TURN-061 뜻 표의 `object-more`(줄임표)다. 새 아이콘은 만들지 않았다. 새 스타일은 `src/ui/header-bar.css` 와 `src/ui/help-panel.css` 에 두었고 `styles.css` 에는 더하지 않았다. 글자·간격은 `--fs-*` · `--sp-*` 만 쓴다.

## 화면

Headless Chrome. 기기 픽셀 배율 1. 콘솔 오류 0.

1280×800 헤더와 6단계 도움말: 문서 스크롤 0 (`scrollWidth` 1280, `scrollHeight` 800). 헤더 넘침 0. 단추는 모두 한 줄이고 「더 보기」는 없다. 도움말을 열기 전후 작업 칸 너비는 1056px 로 같다. 겹친 칸은 오른쪽 320px, 위 180px. rev 1, Undo 0.

1440×900: 도움말을 열면 작업 칸이 1216px 에서 896px 로 줄고, 칸은 나란히 선다.

## 하지 않은 것

- 헤더 색 · 로고 · 새 명령 단추 · 도움말 글 · 용어 풀이
- 1024 미만 모바일 배치
- `README.md`, `release/` 재빌드, 의존성, `styles.css` 에 규칙 추가

## 확인 필요

- 헤더가 정돈돼 보이는가, 도움말을 켜 두고 작업할 만한가(AC9)는 사람 검수다. 이 문서는 완료로 적지 않는다.
- 1280 에서는 지금 단추가 한 줄에 다 들어가 「더 보기」가 없다. 1024 를 포함한 1280 미만은 내보내기 · 보기 설정 · 도움말 · 실행 취소 이력을 항상 메뉴에 넣는다. 1280 이상 1440 미만에서 실제로 넘칠 때만 뒤에서부터 메뉴로 들어간다. main 을 머지하면서 TURN-067 의 이력 단추를 그 뒤에 더해진 항목으로 넣었다.
- 접힌 뒤의 단추 글자는 「펼치기」다. 끌어 옮기기는 화면의 왼쪽 / 오른쪽 가장자리에만 붙는다.
