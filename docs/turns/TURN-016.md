# TURN-016 헤더 아이콘 — 흰 타일 위 진홍 아이콘

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

헤더의 「Aurora Concept Designer」 앞 마크를 흰 둥근 타일 안의 진홍 아이콘으로 바꿨다. 경로는 TURN-015 와 같다. 「A」윤곽, 왼쪽 출력 포트는 채운 원, 오른쪽 입력 포트는 빈 원, 둘 사이는 점선 `1.6 1.4` 다.

| 요소 | 크기 | 색 |
|---|---|---|
| 타일 `.logo-tile` | 32×32px, 모서리 반지름 7px, 테두리 없음 | 채움 `var(--header-fg)` |
| 안쪽 SVG | 22×22px, viewBox 24×24, 선 2.2 | 선과 채운 원 `var(--header-bg)` |

타일과 제목 사이는 `.brand` 의 10px 이다. 헤더는 높이 64px 그대로이고, 타일과 제목은 세로 가운데다. 아이콘은 `aria-hidden="true"` 이고, `.brand` 의 `aria-label` 은 이름과 버전 그대로다. 마크는 `src/ui/BrandMark.tsx` 한 곳이다. 홈과 그 다음 화면도 같은 헤더를 쓴다.

탭 아이콘은 바꾸지 않았다. `index.html` 은 이 변경에 없다.

## 화면 (1280×800)

Chrome 157.0.8103.50 으로 개발 서버를 열어 찍었다. devicePixelRatio 1. 콘솔 오류 0. 라이트와 다크의 헤더 배경은 모두 `rgb(162, 0, 52)` 이다.

- 타일 32×32, 채움 `rgb(255, 255, 255)`, 반지름 `7px`, 테두리 `0px`. 위치 x=24, y=15.5.
- 아이콘 22×22, 선 `rgb(162, 0, 52)`, 선 두께 `2.2px`. 타일 한가운데(가로·세로 차이 0).
- 타일과 제목 간격 10px. 제목 오른쪽 끝과 저장 버튼 사이 628px. 타일·제목·저장 버튼은 겹치지 않는다.
- 타일과 제목의 세로 중심은 둘 다 y=31.5 다. 헤더 테두리 상자 중심은 y=32 다. 헤더 높이 64px 안에 아래 경계 1px(`#7A0027`)이 들어 있어, 내용 영역의 가운데가 테두리 상자 중심보다 0.5px 위다. 헤더 높이와 경계는 바꾸지 않았다.
- 1단계(입력·에셋 선택)에서도 같은 헤더다. 라이트에서 다크로 바꿔도 타일과 아이콘 색은 같다.

- 홈, 라이트: `TURN-016-light-1280.png`
- 홈, 다크: `TURN-016-dark-1280.png`

## 검증

구분해서 적는다. 통과 판정은 CI 를 따른다.

| 종류 | 결과 |
|---|---|
| 자동 테스트 | 로컬 `npm test` 26파일 428개 통과. 그 가운데 `tests/ui-turn015.test.tsx` 3개. 헤더 단언은 32px 타일·22px 아이콘·선 2.2·`var(--header-bg)`·`var(--header-fg)` 로 고쳤다. TURN-015 의 20px `currentColor` 단언은 이번 모양과 맞지 않아서다. favicon data URI 단언은 그대로다. jsdom 은 `background: var(--header-fg)` 를 풀지 못해 타일 배경이 투명으로 남는다. 테스트는 CSS 규칙의 변수와 `.app` 에 붙은 토큰 `#FFFFFF` · `#A20034` 를 본다. 이 숫자는 이 문서 작성 시점의 로컬 실행이다 |
| 형식 검사 | 로컬 `npm run typecheck` 통과 |
| 빌드 | 로컬 `npm run build` 통과. 만들어진 HTML 은 커밋하지 않고 되돌렸다. `release/` diff 없음 |
| Chrome | 157.0.8103.50, CSS 뷰포트 1280×800, devicePixelRatio 1. 위 측정. 라이트·다크·1단계에서 헤더 마크가 같다 |

- 타일 32px · 아이콘 22px · 선 2.2 는 루카 결정 그대로다. 다르게 둘 이유는 없다.
