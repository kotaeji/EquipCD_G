# TURN-088 시각을 이 컴퓨터의 시간으로 보여 주기

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `release/` 는 다시 빌드하지 않았다. `README.md` 는 이 TURN 에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

화면과 내보낸 문서에서 사람이 읽는 시각을 `src/ui/localClock.ts` 한 함수로 모았다. 형식은 `2026-11-27 22:46 (UTC+9)` 다. 날짜, 시, 분, 그리고 시간대 차이다. 알림 이력만 초까지 붙여 `2026-11-27 22:46:32 (UTC+9)` 다. 시간대가 UTC 이면 `(UTC)` 다. 음수와 30분 · 45분 단위도 같다.

이 형식을 쓰는 곳:

- 5단계 「확인 이력」 표. 칸의 `title` 은 저장된 ISO(UTC).
- 확인자 창의 「기록 시각」. 창을 연 순간의 시각이고, `title` 은 그 순간의 ISO.
- 확인된 값 옆의 「확인: 이름 · 시각」.
- 실행 결과 보고서 HTML 의 「내보낸 시각」. `data-exported-at` 과 `title` 은 ISO.
- 인쇄용 보기 표지의 「시각」.
- 작업 정보 줄. `title` 은 저장 · 임시 저장의 ISO.
- 복구 창 · 저장 안 된 작업 · 최근 프로젝트의 시각.
- 알림 이력. `<time>` 의 `dateTime` 과 `title` 은 ISO.

파일 안의 값은 그대로다. 프로젝트 파일, Workspace 묶음, Export 초안, 임시 저장의 시각은 ISO(UTC) 다. 내려받는 파일 이름의 `YYYYMMDD-HHMM` 도 UTC 다. 가상 시간 `00:11.100` 은 바꾸지 않았다.

지금 내려받는 CSV 의 시각 열은 가상 시간뿐이다. 그 머리(「가상 시각」, 「시작」, 「끝」)에는 `(UTC)` 를 붙이지 않았다. 벽시계 시각을 ISO 로 담는 열은 `utcCsvHeader` 가 `시각 (UTC)` 처럼 붙인다.

## 화면 (1280×800)

Headless Chrome. 기기 픽셀 배율 1. 프로세스 시간대 `Asia/Seoul`. 콘솔 오류 0. 앱 문서 스크롤 0 (`scrollWidth` 1280, `scrollHeight` 800).

예제 갤러리의 5공정 예제를 포인터로 열고, 보기 설정에 확인자 이름 「김검토」를 키보드로 넣었다. 가정 체크를 끄고 Interlock 을 확인한 뒤 5단계 「진단·저장·AML」의 확인 이력이다. 표의 시각은 `2026-11-27 23:17 (UTC+9)` 이고, 칸의 `title` 은 `2026-11-27T14:17:35.909Z` 였다. rev 3, Undo 2.

- 확인 이력, 라이트: `TURN-088-log-light-1280.png`
- 확인 이력, 다크: `TURN-088-log-dark-1280.png`

같은 실행을 끝까지 계산한 뒤 「HTML 보고서」를 받아 브라우저로 열었다. 머리는 가상 시각 `00:11.100` 그대로다. 문서 아래 「내보낸 시각」은 `2026-11-27 23:17 (UTC+9)` 이고, `title` 은 `2026-11-27T14:17:37.359Z` 였다. 보고서 문서의 `scrollHeight` 는 3868 이다. 어두운 쪽은 `prefers-color-scheme: dark` 다.

- 보고서 머리, 라이트: `TURN-088-report-head-light-1280.png`
- 보고서 머리, 다크: `TURN-088-report-head-dark-1280.png`
- 내보낸 시각, 라이트: `TURN-088-report-light-1280.png`
- 내보낸 시각, 다크: `TURN-088-report-dark-1280.png`

## 하지 않은 것

- 시간대를 고르는 설정, 12시간제, 언어별 날짜 형식
- 파일 형식, 실행 규칙, 가상 시간
- `README.md`, `release/` 재빌드, 의존성 추가, `styles.css` 에 규칙 추가
- 묶음 화면과 Workspace 패널의 `toLocaleString` (이 TURN 의 적용 목록 밖)

## 확인 필요

- AC9 는 Matthew 검수 전이다. 이 문서는 완료로 적지 않는다.
- 확인자 창의 시각은 창을 연 순간이다. 확인을 누를 때 파일에 들어가는 ISO 는 그 직후다.
- 알림 이력만 초가 있다. 나머지 화면은 분까지다. 함수는 하나다.
- 내려받는 CSV 에는 벽시계 시각 열이 없다. 가상 시간 머리에는 `(UTC)` 를 붙이지 않았다. 벽시계 열을 만들면 `utcCsvHeader` 가 `(UTC)` 를 붙인다.
- 묶음 화면의 「저장 시각」과 Workspace 패널의 저장 시각은 아직 `toLocaleString` 이다.
- `docs/FEATURE-LIST.md` 와 사용자 매뉴얼은 아직 「시각은 UTC」라고 적혀 있다. 이 TURN 은 그 파일을 고치지 않았다.
- 로컬 참고는 `npm test` 145파일 1143개, `tsc --noEmit` 통과. 통과 판정은 CI다. CI 확인 대기 — 루카가 Actions로 확인.
