# TURN-004 헤더 브랜드색

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식 `0.2.0` 과 실행 규칙은 바꾸지 않았다. `release/` 는 다시 빌드해 커밋하지 않았다.

## 한 일

화면 맨 위 `.app > .header` 만 라이트, 다크, 저장값 C 에서 같은 브랜드색을 쓴다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| header-bg | #A20034 | 헤더 배경 |
| header-fg | #FFFFFF | 제품명, 헤더 글자 |
| header-muted | #F5D6DE | 논리 시뮬레이션, 저장 상태 |
| header-border | #FFFFFF | 저장·보조 버튼 테두리와 포커스 링과 같은 흰색 |

헤더 아래 경계는 1px #7A0027 이다. 제품명 크기 20px, 굵기 700 은 그대로고 색만 바꿨다. 로고 규칙의 글자 크기는 그대로고 색만 header-fg 로 바꿨다. 지금 헤더 마크업에는 로고 요소가 없다.

헤더 안 버튼만 따로 덮었다.

| 버튼 | 기본 | 호버 |
|---|---|---|
| 저장 | 배경 #FFFFFF, 글자 #A20034, 테두리 #FFFFFF | 배경 #F5D6DE. 링 없음 |
| 내보내기, 보기 설정 | 배경 투명, 글자 #FFFFFF, 테두리 1px #FFFFFF | 배경 rgba(255,255,255,.12). 링 없음 |
| 실행 취소, 다시 실행 | 배경 투명, 테두리 투명, 글자 #FFFFFF. 비활성 opacity .5 | 배경 rgba(255,255,255,.12), 테두리 투명. 링 없음 |

헤더 안 `:focus-visible` 만 흰 2px outline 과 2px offset 이다. 호버 규칙에는 outline 이 없다. 헤더 밖 포커스 링은 파랑 또는 다크의 accent, offset 1px 그대로다.

## 하지 않은 것

- 탭 바, 스텝퍼, 탐색기, 상태 표시줄, 헤더 밖 버튼 색
- 테마 저장값 A/B/C 매핑. 저장값 C 는 읽을 때 지우지 않고, 칠할 때는 라이트 팔레트를 쓴다
- 프로젝트 JSON, rev, Undo
- `release/` 재빌드 커밋
- `.header .crumb` 색. 현재 헤더에 crumb 가 없어 검토에서 이번 범위 밖으로 두었다
- 사람 검수

## 검증

구분해서 적는다.

| 종류 | 결과 |
|---|---|
| 자동 테스트 | `npm test` 14파일 355개 통과. 헤더 icon 배경 투명·글자 흰색, 호버 규칙에 outline 없음, 포커스 링, 테마 전환을 포함한다. 이 숫자는 이 문서 작성 시점의 로컬 실행이다. 통과 판정은 CI 를 따른다 |
| 형식 검사 | `npm run typecheck` 통과 |
| 빌드 | `npm run build` 통과. 만들어진 HTML 은 커밋하지 않고 되돌렸다 |
| jsdom | 브라우저가 아니다. `getComputedStyle` 이 `var(--header-bg)` 를 풀지 못해 헤더 배경이 투명으로 남는다. 테스트는 `.app` 에 붙은 토큰 `#A20034` 를 `rgb(162, 0, 52)` 로 환산한다. icon 버튼의 배경·테두리는 리터럴이라 jsdom 에서도 `rgba(0, 0, 0, 0)`, 글자는 `rgb(255, 255, 255)`, 비활성 opacity 0.5 로 계산된다 |
| Chrome | 156.0.8078.47, CSS 뷰포트 1280×800, devicePixelRatio 1. 라이트·다크 헤더 배경 `rgb(162, 0, 52)`. icon 은 배경·테두리 투명, 글자 흰색, 비활성 opacity 0.5. 라이트 한 장에서 저장 호버 배경은 `rgb(245, 214, 222)` 이고 포커스 링이 없으며, 내보내기 키보드 포커스는 `rgb(255, 255, 255) solid 2px`, offset 2px 이다 |

그림은 이 폴더에 있다.

- `docs/turns/TURN-004-dark-1280.png`
