# TURN-004 헤더 브랜드색

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식 `0.2.0` 과 실행 규칙은 바꾸지 않았다. `release/` 는 다시 빌드해 커밋하지 않았다.

## 한 일

화면 맨 위 `.app > .header` 만 라이트, 다크, 저장값 C 에서 같은 브랜드색을 쓴다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| header-bg | #A20034 | 헤더 배경 |
| header-fg | #FFFFFF | 제품명, 헤더 글자 |
| header-muted | #F5D6DE | 논리 시뮬레이션, 저장 상태 |
| header-border | #FFFFFF | 버튼 테두리와 포커스 링과 같은 흰색 |

헤더 아래 경계는 1px #7A0027 이다. 제품명 크기 20px, 굵기 700 은 그대로고 색만 바꿨다. 로고 규칙의 글자 크기는 그대로고 색만 header-fg 로 바꿨다. 지금 헤더 마크업에는 로고 요소가 없다.

헤더 안 버튼만 따로 덮었다.

| 버튼 | 기본 | 호버 |
|---|---|---|
| 저장 | 배경 #FFFFFF, 글자 #A20034, 테두리 #FFFFFF | 배경 #F5D6DE |
| 내보내기, 보기 설정 | 배경 투명, 글자 #FFFFFF, 테두리 1px #FFFFFF | 배경 rgba(255,255,255,.12) |
| 실행 취소, 다시 실행 | 글자 #FFFFFF. 비활성 opacity .5 | 헤더 안에서는 accent 테두리를 쓰지 않고 흰 2px outline |

헤더 안 `:focus-visible` 은 흰 2px outline 과 2px offset 이다. 헤더 밖 포커스 링은 파랑 또는 다크의 accent, offset 1px 그대로다.

## 하지 않은 것

- 탭 바, 스텝퍼, 탐색기, 상태 표시줄, 헤더 밖 버튼 색
- 테마 저장값 A/B/C 매핑. 저장값 C 는 읽을 때 지우지 않고, 칠할 때는 라이트 팔레트를 쓴다
- 프로젝트 JSON, rev, Undo
- `release/` 재빌드 커밋
- 사람 검수

## 검증

구분해서 적는다.

| 종류 | 결과 |
|---|---|
| 자동 테스트 | `npm test` 14파일 354개 통과. 헤더 토큰, 대비, 포커스 규칙, jsdom 테마 전환을 더했다. 이 숫자는 이 문서 작성 시점의 로컬 실행이다. 통과 판정은 CI 를 따른다 |
| 형식 검사 | `npm run typecheck` 통과 |
| 빌드 | `npm run build` 통과. 만들어진 HTML 은 커밋하지 않고 되돌렸다 |
| jsdom | 브라우저가 아니다. `getComputedStyle` 이 `var(--header-bg)` 를 풀지 못해 헤더 배경이 투명으로 남는다. 테스트는 `.app` 에 붙은 토큰 `#A20034` 를 `rgb(162, 0, 52)` 로 환산한다. 테두리 `#7A0027` 은 jsdom 에서도 `rgb(122, 0, 39)` 로 계산된다 |
| Chrome | 156.0.8078.47, CSS 뷰포트 1280×800, devicePixelRatio 1. 라이트와 다크 헤더 배경이 둘 다 `rgb(162, 0, 52)`. 저장값 C 를 넣고 다시 열어도 저장값은 C, 보이는 모양은 라이트, 헤더 배경은 같다. 상태줄 rev 1, Undo 0. 헤더 아래 736px 는 바꾸기 전과 픽셀 차이가 0 이다. 라이트 헤더 줄 81920픽셀은 모두 달라졌다 |

대비는 같은 계산으로 흰색 대 #A20034 가 8.12:1, #F5D6DE 대 #A20034 가 6.02:1 이다. 저장 버튼 글자 #A20034 는 헤더 배경과 같아서 헤더 배경 기준으로는 1:1 이다. 자동 테스트는 그 글자를 버튼 면(#FFFFFF, 호버 #F5D6DE)과 재어 8.12:1, 6.02:1 이다.

헤더 안 저장 버튼에 키보드 포커스를 주면 outline 은 `rgb(255, 255, 255) solid 2px`, offset 2px 이다. 이어서 탭한 탐색기 쪽 버튼은 offset 1px, 색 `rgb(36, 91, 206)` 이다.

## 확인 필요

- 실행 취소와 다시 실행은 글자 #FFFFFF 와 비활성 opacity .5 만 정해져 있다. 배경과 테두리는 기존 버튼 색이다. 라이트에서는 흰 글자가 흰 버튼 위에 있어 화살표가 보이지 않고, 반투명 흰 네모만 보인다. 다크에서는 어두운 버튼 위에 흰 화살표가 보인다. 배경을 투명으로 둘지는 결정 밖이라 바꾸지 않았다.
- `.header .crumb` 색은 이슈가 정하지 않아 그대로 두었다. 현재 헤더 마크업에는 crumb 가 없다.
- AC2 문장은 버튼 글자도 헤더 배경과 재라고 읽힌다. 결정된 저장 버튼 글자는 헤더와 같은 #A20034 라 그 기준으로는 대비가 되지 않는다. 테스트는 버튼 면을 기준으로 했다.
- AC7 사람 검수는 Matthew 몫이다. 이 문서는 완료로 적지 않는다.
