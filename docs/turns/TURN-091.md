# TURN-091 자재 종류를 색과 글자로

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.10.0`. `README.md` 는 고치지 않았다. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

정의가 둘 이상일 때 종류 순서 1~4 에 색 토큰 `--mat-1` ~ `--mat-4` 를 둔다. 글자(표식)는 항상 같이 나오고, 무늬는 민무늬 · 빗금 · 점 · 가로줄이다. 정의가 하나이면 색과 범례를 두지 않는다. 모델 · 파일 형식 · 실행 로그는 바꾸지 않는다.

- 라이트: `#1690ce` · `#d26b3f` · `#1a9c50` · `#b85bfa`
- 다크: `#2775ad` · `#aa5b26` · `#237f54` · `#9e45d2`
- 글자는 `--text` 다. 네 색은 라이트 · 다크에서 배경(bg · panel · canvas) 3:1 이상, 글자 4.5:1 이상이다.
- 적용: 2 · 6단계 도면의 자재 표식, 3D 자재 색(`describe.ts` 의 `kindColor`, `Scene3D` 는 그 값만 읽음), 개체 표의 종류 칸, 실행 요약 · 실행 줄의 종류별 줄, 타이밍 차트 개체 줄과 범례, 4단계 자재 종류의 정의 줄 · 투입 순서 칸, 보고서 HTML, 인쇄용 보기.
- 범례(색 · 무늬 · 글자 · 이름)는 정의가 둘 이상일 때만 도면과 타이밍 차트에 생긴다.
- 표식을 비운 칸은 자동 글자(A · B · C · D)를 placeholder 로 흐리게 보여 준다. 저장 값은 빈 값이다.

## 화면 (1280×800)

Headless Chrome. 기기 픽셀 배율 1. 콘솔 오류 0. 문서 스크롤 0 (`scrollWidth` 1280, `scrollHeight` 800). 포인터 클릭과 키 입력(표식 칸 Ctrl+A · Backspace · Tab, 투입 순서 · 투입 개수 · 투입 간격)으로 확인했다.

5공정 예제에 정의를 하나 더하고 표식 B 를 비운 뒤 투입 순서를 `A, A, B`, 투입 개수 6, 간격 1초로 실행해 종류 B 가 도면에 나온 순간(가상 시간 `00:03.767`)에 멈췄다. 도면의 자재는 A 민무늬 `--mat-1` 두 개, B 빗금 `--mat-2` 한 개다. 3D `data-scene-kind` 는 `--mat-1 --mat-1 --mat-2` 다.

## 하지 않은 것

- 색을 사용자가 고르기, 종류 5개 이상
- 3D 시점 · 맞춤, Device 도형, 3D 무늬(3D 는 색만)
- `README.md`, `release/` 재빌드, 의존성 추가, 범위 밖 리팩터링
- 실행 규칙 · 파일 형식

## 확인 필요

- 혼류가 한눈에 읽히는지는 사람 검수(AC9)다. 이 문서는 완료로 적지 않는다.
- 정의가 하나인 예제의 빈 표식 칸에도 흐린 `A` 가 자리 표시로 보인다. 저장 바이트와 실행 로그는 그대로다. 색과 범례는 없다.
- 다크 네 색은 패널 대비가 3.01:1 근처다. 검사는 3:1 을 넘는다.
- 흑백 인쇄는 글자와 무늬(민무늬 · 빗금 · 점 · 가로줄)로 읽힌다. 보고서 · 인쇄용 보기는 라이트 색을 쓰고, 화면 다크는 다크 색을 쓴다.
