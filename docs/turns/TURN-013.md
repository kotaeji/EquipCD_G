# TURN-013 도면 Unit 크기 — Device를 감싸고, 모서리로 조절

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 바뀐 조작

1. Device를 Unit 밖으로 옮기면, 그 Unit이 Device와 여백을 감싸도록 커진다. 왼쪽·위로 나가면 Unit의 위치도 따라 움직인다. 이동과 크기 변경은 Undo 한 번이다.
2. 「선택/이동」에서 Unit을 고르면 오른쪽 아래 모서리 손잡이가 보인다. 끌면 미리보기만 바뀌고, 놓으면 크기가 한 번 반영된다. Unit의 왼쪽 위 자리는 그대로다.
3. 「크기 맞춤」은 소속 Device를 감싸는 최소 크기로 줄인다. Device가 없으면 216×300이다. 카드 보드에서 같은 Unit에 Device를 놓으면 겹치지 않는 다음 자리에 들어간다.

## 한 일

- 크기 계산은 `src/model/unitLayout.ts` 한 곳이다. 머리글 28px, 안쪽 여백 12px. `moveNodes` · `alignNodes` · `addDevice` · `addUnitFromTemplate` · `reparentDevice` 가 `fitUnit` 을 부른다. 자동으로는 커지기만 한다. 소속이 빠진 원래 Unit은 줄이지 않는다.
- 손잡이는 `@xyflow/react` 의 `NodeResizeControl` 하나(오른쪽 아래)다. 모델 반영은 `resizeUnit` 이다. 소속 Device를 자르는 크기에서 멈춘다.
- 실행 중에는 손잡이를 보이지 않는다. 「크기 맞춤」을 누르면 모델 편집 차단 문구가 나온다.
- 이웃 Unit은 밀지 않는다. 상자가 겹치면 테두리가 경고색이다. 겹친 곳에 놓는 Unit은 지금처럼 나중에 만든 Unit이다.
- 예제 파일을 열기만 해서는 rev와 Unit 크기가 바뀌지 않는다.

## 하지 않은 것

- 자동으로 줄이기. 줄이기는 「크기 맞춤」만
- 이웃 Unit 밀기, Device 크기 바꾸기, 카드 보드 카드 크기
- 서브플로, 배경 도면, 잠금, 프로젝트 파일 형식 변경, 의존성 추가, `release/` 재빌드
- `docs/FEATURE-LIST.md`, 사용자 매뉴얼

## 확인 필요

- AC11은 Matthew 검수 전이다. 이 문서는 완료로 적지 않는다.
- 여백은 지금 그림의 머리글(28px)과, 예제에서 가장 빡빡한 위쪽 간격(갠트리, 12px)에 맞췄다. 다르게 잡아야 하면 말한다.
