# TURN-067 실행 취소 이력 목록

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `README.md` · `release/` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

헤더의 실행 취소 · 다시 실행 옆에 「이력」이 있다. 누르면 지금 프로젝트 탭의 편집이 최신부터 나온다. 줄에는 편집 이름과 그때의 rev가 있고, 지금 줄에는 「지금」이 붙는다. 그보다 위, 다시 실행할 수 있는 줄은 흐리다. 줄을 누르면 그 시점의 모델이 된다. 실행 취소를 그만큼 한 것과 같고, 위쪽 줄은 다시 실행을 그만큼 한 것과 같다. 목록은 닫히지 않아서 다시 앞으로 올 수 있다. 새 편집을 하면 다시 실행 쪽은 사라진다.

실행 취소 단추의 툴팁은 「실행 취소: 신호 기다림 추가 (Ctrl/Cmd+Z)」처럼 다음에 취소될 이름을 말한다. 다시 실행도 같다. 취소할 것이 없으면 예전처럼 이름 없이 단축키만 보인다.

이력은 탭마다 따로이고 저장하지 않는다. 다시 열면 비어 있다. 한도는 지금과 같이 100이다. 넘치면 오래된 편집부터 빠지고, 이름이 없는 줄은 「편집」이다. 실행 중에는 목록이 보이지만 줄이 막히고 「실행 중에는 Undo가 차단됩니다」가 보인다.

명령 찾기에 「실행 취소 이력」이 있다. 아이콘은 TURN-061 뜻 표의 `History`다. 스타일은 `src/ui/history-list.css`다. `styles.css`에는 더하지 않았다.

## 화면 (1280×800)

5공정 예제, 4단계. 「신호 기다림 추가」 다음 「Substation 시퀀스 넣기」를 하고 실행 취소를 한 번 눌렀다. rev 2가 지금이고, rev 3은 흐리다. 아래 「처음」은 이 탭을 열었을 때의 rev 1이다. 위쪽 줄을 누르면 rev 3이 되고 목록은 그대로다. 다크도 같은 내용이다.

## 하지 않은 것

- 이력을 저장해 다시 열어도 남기기, 가지치기, 편집 사이 차이 보기
- `README.md`, `release/` 재빌드, 의존성 추가
- 이미 있는 `edit(…, label)` 이름을 다른 말로 바꾸기. 비어 있는 이름만 「편집」으로 보인다.

## 확인 필요

- AC9는 Matthew 검수 전이다. 이 문서는 완료로 적지 않는다.
- 편집이 시작되기 전 시점을 「처음」으로 두었다. 그 줄을 누르면 이 탭을 열었을 때의 모델로 돌아간다. 한도를 넘어 이름이 사라진 가장 오래된 시점은 「편집」이다.
- 다시 실행은 편집 이름을 `redo`로 바꾸지 않고 원래 이름을 남긴다. 목록에서 다시 앞으로 올 때 같은 이름이 보이게 하려고다.
