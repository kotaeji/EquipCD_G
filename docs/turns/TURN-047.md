# TURN-047 자동 임시 저장과 복구

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `README.md` · `release/` · `src/runtime/` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

편집한 뒤 5초가 지나면 그 프로젝트를 이 브라우저에만 임시 저장한다. 이어서 편집하면 마지막 편집부터 한 번만 쓴다. 저장 목록, 저장된 rev, 「● 저장 안 됨」은 바꾸지 않는다. 쓰기는 기존 저장과 같은 원자 쓰기와 형식 검사를 쓴다.

앱을 열거나 저장된 프로젝트를 열 때, 임시 저장이 저장본보다 새 rev이고 시각이 더 오래되지 않았으면 「저장 안 된 변경이 있습니다」를 묻는다. 복구는 임시 저장 내용으로 열고 저장 안 됨이며 Undo는 비어 있다. 버리기는 저장본을 열고 임시 저장을 지운다. 한 번도 저장하지 않은 임시 저장은 시작 화면의 최근 프로젝트 위에 「저장 안 된 작업」으로 보인다.

저장, 저장하지 않고 닫기, 프로젝트 삭제는 그 임시 저장을 지운다. 깨진 임시 저장은 복구를 권하지 않고 격리 보관함으로 보낸 뒤 저장본으로 연다. 저장소를 쓸 수 없거나 쓰기가 실패하면 편집과 Undo는 그대로 두고 작업 정보 줄에 「임시 저장 실패」만 보인다. 실행 중이거나 일시정지 중에는 쓰지 않는다. 보기 설정의 「자동 임시 저장」은 기본으로 켜져 있고 이 브라우저에 기억된다.

작업 정보 줄은 `저장 14:02 · 임시 저장 14:05`처럼 마지막 저장 시각과 임시 저장 시각을 한 줄에 보여 준다.

## 하지 않은 것

- 「저장」 없이 저장본을 자동으로 덮어쓰기
- 버전 이력, 다른 기기·다른 브라우저와 맞추기
- Workspace 파일 묶음
- `README.md`, `release/` 재빌드, `src/runtime/`, `Inspector.tsx`, `Canvas.tsx`, 의존성 추가

## 확인 필요

- 「자동 임시 저장」을 꺼도 이미 있는 임시 저장은 복구 창과 「저장 안 된 작업」에 남는다. 끄면 새 임시 저장만 멈춘다.
- 임시 저장 시각이 저장본보다 오래되면 rev가 더 커도 묻지 않는다. 시각이 같거나 더 새롭고 rev가 더 클 때만 묻는다.
- 실행·일시정지 중에는 쓰지 않고, 초기화로 다시 편집할 수 있게 된 뒤에 남은 편집을 임시 저장한다.
- 임시 저장 목록 키 자체가 깨지면 원문은 격리하되 그 키는 덮어쓰지 않는다. 그 상태에서는 새 임시 저장이 「임시 저장 실패」로 남는다.
