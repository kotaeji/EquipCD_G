# TURN-062 작은 마무리 묶음

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. 파일 형식은 `0.3.0`. 실행 규칙은 `seq-runtime/0.6.0`. `README.md` 와 `release/` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

1. **기다림 시간 초과** — `WAIT_TIMEOUT` 이 6단계 오류 칸과 「자세히」에 세 줄로 나온다. 무엇은 블록 이름, 왜는 기다린 조건의 한 줄 식과 기다린 시간, 어떻게는 조건을 바꾸는 단계와 타임아웃 확인이다. 「이동」은 그 흐름 줄을 연다. 실행 전 차단 `WAIT_TIMEOUT_UNDEFINED` 도 블록 이름 / 타임아웃 미정 / 타임아웃을 확인하는 단계의 세 줄이다. 판정과 코드는 그대로다.
2. **도움말 매뉴얼 줄** — 칸에는 「매뉴얼 6.2 도면 도식」처럼 절 번호와 제목만 보인다. 기능 ID와 백틱은 빼었다. 저장된 제목은 매뉴얼 머리글과 그대로 맞는다.
3. **둘러보기** — 마지막 걸음의 단추는 「끝내기」다. 누르면 지금처럼 둘러보기가 끝난다. 앞 걸음은 「다음」이다.
4. **다음 차단** — 6단계 실행 전 차단이 2개 이상이면 목록 위에 「남은 차단 N개」가 보인다. 「이동」으로 고치러 갔다가 6단계로 돌아오면 남은 차단의 첫 줄이 강조된다. 차단 판정은 바꾸지 않았다.

새 스타일은 `src/ui/problem.css` 에 두었고 `styles.css` 에는 더하지 않았다. 글자·간격은 `--fs-*` · `--sp-*` 만 쓴다.
