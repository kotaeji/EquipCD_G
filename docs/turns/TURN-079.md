# TURN-079 인쇄 · 보고용 보기

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `README.md` 와 `release/` 는 이 TURN에서 고치지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 한 일

헤더 「내보내기」가 메뉴가 되었다. 글자와 아이콘은 그대로 「내보내기」이고, 메뉴 안에 「JSON 내보내기」와 「인쇄용 보기」가 있다. 명령 찾기에서도 「인쇄용 보기」를 연다. 아이콘은 TURN-061 표의 `Printer`다.

인쇄용 보기는 넣을 구역을 체크로 고른다. 표지, 장비 구조, 도면 도식, Station 시퀀스, Substation 시퀀스, SFC, 신호 · Interlock, 가정 · 미정 · Gap. 용지는 가로(기본)와 세로. 「인쇄」는 `window.print`다. 「닫기」와 Esc는 보기를 닫고, 열기 전의 단계로 돌아온다. rev 와 Undo 는 바꾸지 않는다.

표지와 쪽 머리에 프로젝트 이름과 한계 문구가 있다. 한계 문구는 `논리 시뮬레이션 — 실제 장비 제어 / 안전 검증 아님 · 검토 후보`다. 표지에는 rev, 날짜, 앱 버전도 있다. 인쇄는 테마와 상관없이 흰 배경 · 검은 글씨다. 단추, 탐색기, 작업 줄, 단계 바, 상태 줄, 알림은 인쇄에 나오지 않는다.

흐름 표는 들여쓰기를 유지한다. 표는 `thead`가 있고, 인쇄에서 머리 줄이 반복되며 줄 중간에서 끊지 않는다. 구역은 새 쪽에서 시작한다. 쪽 번호는 아래 가운데다. 도면과 SFC는 SVG이고, 도면은 화면의 확대 · 이동과 무관하게 지금 모델 전체를 한 쪽 너비에 맞춘다.

스타일은 `src/ui/print-view.css`다. `styles.css`에는 더하지 않았다. 글자 · 간격은 `--fs-*` · `--sp-*`다.
