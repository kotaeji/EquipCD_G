# TURN-003 웹 화면

검토 후보입니다. 사람 검수가 끝나기 전에는 정식 릴리스가 아닙니다. 앱 버전은 `0.3.0-prototype` 그대로입니다. 파일 형식 `0.2.0`과 실행 규칙은 바꾸지 않았습니다.

기준은 공개 `main` `179ac28`(PR #5 병합)입니다. PR #5는 이미 병합되어 있어 그 브랜치나 `main`을 직접 고치지 않았습니다.

## 설계 출처

공식 파일: https://www.figma.com/design/q5gKgslqjwByXykymfZkUh

구현 색·간격·배치는 그 파일의 `get_design_context` 응답(기본 화면 31, 상태 17, 같은 시작 화면의 다크 1, 공통 요소 5)을 기준으로 했습니다. 스크린샷은 비교 대상이며 앱 그림으로 넣지 않았습니다. 인계 압축 전체는 저장소에 복사하지 않았습니다.

색은 화면색 컬렉션의 라이트(모드 1:1)와 다크(모드 1:2)를 별칭이 가리키는 값으로 풀었습니다. 참고 문맥에 적힌 라이트 대체색을 다크에 고정하지 않았습니다. 보관 모드 1:3은 선택지에 없습니다.

간격 4/8/12/16/24/32, 모서리 6/12, 기본 폭 1280, 탐색 224. 1920에서는 탐색 224와 라이브러리 상세 256을 유지하고 가운데만 넓힙니다. 글자는 Noto Sans KR(한글·라틴, 굵기 400·700, 앱에 포함)입니다.

## 저장값 C

| 저장값 | 보이는 색 | 저장 파일을 언제 바꾸나 |
|---|---|---|
| A | 라이트 | 다크를 누르면 B |
| B | 다크 | 라이트를 누르면 A |
| C | 라이트 | 그대로 둠. 라이트를 누르면 A, 다크를 누르면 B |

C를 읽는 순간 덮어쓰지 않습니다. 프로젝트 JSON, rev, Undo, Workspace 목록에는 테마가 들어가지 않습니다.

## 시안과의 차이

공식 미리보기는 1024×640입니다. 이는 CSS 1280×800의 0.8배 내보내기입니다. 비교 그림은 실제 화면을 0.8배로 줄여 같은 1024×640에 맞춘 뒤 왼쪽에 시안, 오른쪽에 앱을 두었습니다. CSS 뷰포트는 1280×800입니다. 1920×1080에서도 제목은 24px, 탐색은 223px, 입력은 40px였고 Noto Sans KR 700 24px 로드가 참이었습니다. 픽셀 일치를 주장하지 않습니다. 그림은 `docs/user-manual/images/gui-r5/compare/`입니다.

| 화면 | 시각 판정 | 남은 차이 |
|---|---|---|
| S00 | 시작 카드 구조 | 저장 목록이 비어 있으면 예시 행을 만들지 않는다. 바닥 줄에 rev가 있다 |

### S20에서 기능을 지키려고 남긴 차이

시안 중앙은 216px 카드 세 장과 장치 칩이다. 실제 모델은 좌표, 포트, 신호선, 드래그를 가진다. 둘을 한 장에 같은 밀도로 넣으면 시안이 아니게 된다.

- 기본 중앙은 실제 Substation 카드다. 칩을 누르면 선택되고, 다른 카드에 놓으면 소속이 바뀌며, 팔레트에서 놓으면 장치가 추가되고, 물류 연결은 카드를 눌러 만든다.
- 좌표 이동, 포트, 신호선, 실사풍, 정렬, 삭제는 「도면 도식 열기」 안에 있는 기존 캔버스다. 신호 연결을 고르면 그 도면이 열린다. 카드를 정적 그림으로 바꾼 것이 아니다.
- 팔레트 14종은 기본 화면에 세로 열로 두지 않고 한 줄 안내와 접이식 목록으로 둔다.
- 오른쪽은 선택 장치의 실제 속성 요약이다. 전체 편집 칸은 「속성 자세히」에 있다.
- 예제에는 Substation이 다섯이라 S4·S5가 카드 줄 오른쪽으로 이어진다. 시안 프레임은 세 장만 그렸다.
- 확대는 100% 한 칸이 아니라 줄이기·퍼센트·키우기다.
- 머리말의 「미구현 설계 시안」 문구는 쓰지 않는다. 바닥에는 rev와 Undo가 남는다. 트리 아래 「이 브라우저 작업」에 Workspace 전환과 예제 버튼이 있다.

이 차이를 빼고는 S20이 시안과 같다고 말하지 않는다.
