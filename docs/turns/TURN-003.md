# TURN-003 웹 화면

검토 후보입니다. 사람 검수가 끝나기 전에는 정식 릴리스가 아닙니다. 앱 버전은 `0.3.0-prototype` 그대로입니다. 파일 형식 `0.2.0`과 실행 규칙은 바꾸지 않았습니다.

기준은 공개 `main` `179ac28`(PR #5 병합)입니다. PR #5는 이미 병합되어 있어 그 브랜치나 `main`을 직접 고치지 않았습니다.

## 설계 출처

공식 파일: https://www.figma.com/design/q5gKgslqjwByXykymfZkUh

구현 색·간격·배치는 그 파일의 `get_design_context` 응답(기본 화면 31, 상태 17, 같은 시작 화면의 다크 1, 공통 요소 5)을 기준으로 했습니다. 스크린샷은 비교 대상이며 앱 그림으로 넣지 않았습니다. 인계 압축 전체는 저장소에 복사하지 않았습니다.

색은 화면색 컬렉션의 라이트(모드 1:1)와 다크(모드 1:2)를 별칭이 가리키는 값으로 풀었습니다. 참고 문맥에 적힌 라이트 대체색을 다크에 고정하지 않았습니다. 보관 모드 1:3은 선택지에 없습니다.

간격 4/8/12/16/24/32, 모서리 6/12, 기본 폭 1280, 탐색 224. 1920에서는 탐색 224와 라이브러리 상세 256을 유지하고 가운데만 넓힙니다. 글자는 Noto Sans KR(한글·라틴, 굵기 400·700, 앱에 포함)입니다.

## 저장값 C

| 저장값 | 보이는 색 | 저장 파일을 언제 바꾸나 |
|---|---|---|
| A | 라이트 | 다크를 누르면 B |
| B | 다크 | 라이트를 누르면 A |
| C | 라이트 | 그대로 둠. 라이트를 누르면 A, 다크를 누르면 B |

C를 읽는 순간 덮어쓰지 않습니다. 프로젝트 JSON, rev, Undo, Workspace 목록에는 테마가 들어가지 않습니다.

## 공식 SVG

`src/ui/slots/`의 5개. 루트 크기는 100×48 세 개와 16×16 두 개입니다. 원격 주소를 앱이 요청하지 않습니다. 카드의 푸셔(1:585), 실린더(1:594), 바코드리더(1:774), 컨베이어(1:778)에 100×48로 넣었습니다. 인계에서 실린더 칸과 푸셔 칸이 같은 파일을 가리켜 실린더도 그 파일을 씁니다. 접기 단추는 16×16입니다. 나머지 종류의 도식은 기존 기호입니다.

## 시안과의 차이

- 단계 칩의 준비 배지는 화면에서 숨기고 「남은 항목」에 둡니다. 72px 줄에 여섯 단계와 테마가 들어가게 하기 위해서입니다. 판정 계산은 그대로입니다.
- 실린더 도식은 인계 SVG가 푸셔와 같습니다.
- 시작 화면의 최근 목록은 실제 저장본만 보여 줍니다. 설계 예시의 조립 라인 이름이나 rev를 넣지 않습니다.
- 실행 로그의 시각은 그 실행의 가상 시각입니다. 시안의 0.8초 같은 숫자를 고정해 두지 않습니다.
