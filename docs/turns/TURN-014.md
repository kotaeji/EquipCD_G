# TURN-014 도면 Unit 여러 개 — 간격 같게 · 크기 같게 · 겹침 풀기

상태: 검토 후보. 사람 검수 전. 정식 릴리스가 아니다. 앱 버전은 `0.3.0-prototype` 그대로다. `release/` 는 다시 빌드하지 않았다. CI 확인 대기 — 루카가 Actions로 확인.

## 바뀐 조작

1. 도면 도식에서 Unit 을 여러 개 고르면 「배치 ▾」에서 가로 간격 같게, 세로 간격 같게, 너비 같게, 높이 같게, 겹침 풀기를 쓸 수 있다. 선택에 섞인 Device 는 빠지고 Unit 만 움직인다.
2. 간격 같게는 양 끝 Unit 을 두고 사이 빈 간격을 고르게 한다. 크기 같게는 가장 큰 너비·높이에 맞추고 왼쪽 위는 그대로다. 겹침 풀기는 가로로만, 20px 보다 가까운 Unit 을 오른쪽으로 민다.
3. 한 명령은 rev +1, Undo 한 번이다. 이미 같으면 rev 가 오르지 않고 「바뀐 것 없음」이 나온다. 실행 중에는 다섯 명령 모두 지금 차단 문구로 막힌다.

## 한 일

- 계산은 `src/model/commands.ts` 의 `distributeUnits` · `matchUnitSize` · `spreadUnits` 뿐이다. 화면은 다시 계산하지 않는다.
- Unit 을 옮기면 소속 Device 도 같은 만큼 옮긴다. 고르지 않은 Unit 은 움직이지 않는다.
- 크기 맞추기는 TURN-013 의 최소 크기 아래로 줄이지 않는다. 원점은 그대로다.
- 가로·세로 간격 같게의 결과 간격이 0보다 작으면 모델은 바뀌고, 「먼저 겹침 풀기를 누르세요」를 함께 보여 준다.
- 겹침 테두리(`is-overlap`)는 명령 뒤에 상자 위치로 다시 계산된다.
- 1280×800 에서 다섯 단추를 도구 줄에 그대로 넣으면 한 줄을 넘긴다. 줄은 「배치 ▾」 하나다. 조건이 안 되면 항목이 비활성이고, `title` 에 「Unit 을 3개 이상 고르세요」 또는 「Unit 을 2개 이상 고르세요」가 있다.

## 화면 (1280×800, 5공정 예제, 도면 도식, 확대 50%)

Chrome 으로 개발 서버를 열어 찍었다. 맞추기 기본값이라 확대는 50%다. S1~S4 를 고른 뒤 높이와 가로 간격을 흩뜨리고, 「높이 같게」 다음 「가로 간격 같게」를 눌렀다. S5 는 고르지 않아서 그대로다. 도구 줄에 가로 스크롤은 없다.

- 명령 전, 라이트: `TURN-014-before-light-1280.png`
- 배치 메뉴, 라이트: `TURN-014-menu-light-1280.png`
- 명령 뒤, 라이트: `TURN-014-after-light-1280.png`
- 명령 뒤, 다크: `TURN-014-after-dark-1280.png`

## 하지 않은 것

- Device 끼리 간격·크기 맞추기
- 오른쪽·가운데·아래 정렬, 끌어서 사각형으로 고르기
- 선택하지 않은 Unit 을 밀어 내기, 자동 배치
- 최소 간격 20px 을 사용자가 바꾸는 설정
- 카드 보드 탭, 프로젝트 파일 형식, 의존성 추가, `release/` 재빌드
- `docs/FEATURE-LIST.md`, 사용자 매뉴얼

## 확인 필요

- AC11 은 Matthew 검수 전이다. 이 문서는 완료로 적지 않는다.
- 다섯 명령은 이슈가 정한 대로 「배치 ▾」에 넣었다. 1280 에서 도면 도구가 놓이는 칸은 약 768px 이고, 다섯 라벨을 「좌 정렬 · 상 정렬」 옆에 두면 한 줄을 넘긴다.
- 크기 같게는 가장 큰 값에 맞춘 뒤, 그 값이 Device 를 자르면 TURN-013 최소 크기까지 올린다. 보통은 각 Unit 의 현재 크기가 이미 최소 이상이라 결과는 가장 큰 값이다.
