- 기준: `main` `bc0c7c4`(TURN-010 릴리스까지), 2026-11-12. FL-30 · FL-32 · FL-33 · FL-34 · F2 · 사람 검수 표는 TURN-014(`5210e71`)까지, FL-01 은 TURN-016(`530ef96`)까지, FL-12 · FL-13 · FL-20 · FL-24 · FL-26 · FL-34 · FL-54 · FL-63 · FL-70 · FL-71 은 TURN-017~021(`d021a01`)까지 반영. 앱 버전 `0.3.0-prototype`, 파일 형식 `0.2.0`.

## 0. 읽는 법

한 기능을 한 줄로 적는다. 줄마다 다음을 본다.

| 열 | 뜻 |
|---|---|
| ID | 기능 번호 `FL-NN`. 이 문서 안에서만 쓴다 |
| 기능 | 사용자가 할 수 있는 일 |
| 요구 | 요구 ID(C·F·N). 하나의 기능이 여러 요구에 걸칠 수 있다 |
| 화면 | 화면 ID `Sxx`(기본 화면)·`Vxx`(상태 변형). 1절 화면 지도에서 앱 위치와 와이어프레임·UX·GUI 시안 쪽을 찾는다 |
| UX | UX 시나리오 `UX-NN`([`UX-SCENARIOS.md`](UX-SCENARIOS.md)) |
| 상태 | ✅ 구현 · ◐ 일부 구현 · ✗ 미구현 · 📄 안내 화면만(기능 없음) · 👤 사람 검수 대기 |
| 근거 | TURN 기록(`docs/turns/`)과 자동 테스트(`tests/`) |

- 「테스트 통과」는 CI 결과로만 말한다. 이 표의 테스트 이름은 「그 기능을 보는 테스트가 있다」는 뜻이다.
- 화면 ID는 앱 코드(`src/ui/screens.ts` `screenOf`), 와이어프레임·UX·GUI 시안 PDF가 같은 번호를 쓴다. 그래서 「요구 → 기능 → 화면 → 시안」을 화면 ID 하나로 따라갈 수 있다.
- 시안 PDF는 설계 시안이다(2026-11-09 Figma 내보내기). 지금 앱 화면과 다른 곳이 있다. 지금 화면은 각 TURN 기록의 스크린샷을 본다.

### 시안과 지금 앱이 다른 곳

- S01·S02: 시안은 탐색기 안의 관리 칸이다. 지금 앱은 탐색기 위쪽 **Workspace · Project 탭**(TURN-008)이고, 프로젝트는 짧은 목록과 `…` 팝업(TURN-010)이다.
- S00: 시안의 「작업 시작 · 새 프로젝트」 줄은 지금 **작업 정보 줄** `Workspace › Project · rev · 저장 상태`(TURN-008)다.
- S20: 시안은 카드 보드 아래에 도면이 접혀 있다. 지금은 팔레트 아래 **카드 보드 · 도면 도식 탭**(TURN-009)이고, 도면은 React Flow 캔버스(TURN-005)다.
- V13: 시안의 위쪽 프로젝트 탭 바는 지금 없다. 열린 프로젝트는 Project 탭 목록에 있다.
- S71·V14·V15: 시안 일부에 A/B/C 세 테마 표기가 남아 있다. 지금 앱은 라이트·다크 두 개다(TURN-003, 저장값 C 는 보관).
