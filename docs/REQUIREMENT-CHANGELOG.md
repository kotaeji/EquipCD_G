# Aurora Concept Designer — 요구 변경이력

관리 문서 버전: v0.3 / 2026-11-08 KST. 공개 저장소용: 비공개 외부 노트 URL/UUID·계정·개인 자료를 넣지 않는다. 실제 커밋/배포/앱 검증 기록이 아니라 요구 변경 기록이다.

## 기록 원칙

요구 상태(확정/제안/미정), 구현 상태, 검증 상태, 외부 정본 반영 상태를 분리한다. 기존 ID를 삭제/재사용하지 않는다. 명시적으로 개정된 구 요구는 원래 근거와 이력을 남기고 현행 해석을 표시한다. 사용자 입력은 읽기 전용이다. Requirement와 History는 봇이 관리하며 정본 제목은 고정하고 버전은 본문에 둔다.

### 외부 관리 상태와 작성 경계

- 저장·재열기와 export 근거로 History 노트 생성·저장·재열기와 기존 정본 상단 링크 추가가 확인되었다. 신규 v0.3 본문/UX/WF 전체가 외부 노트에 저장되었다는 뜻은 아니다.
- 명세상 요구와 실제 구현·검증 근거를 구분한다. 기존 v0.2 구현·검증 기록은 README, REQUIREMENTS-VERIFICATION, BROWSER-VERIFICATION을 참조한다.
- 별도 UX 봇은 만들지 않았다. 초기 동일 봇 통합 관리를 권고하며 독립 작업이 커지면 역할 분리를 검토한다.
- 디자인 스킬을 검토했지만 본 작업은 텍스트/Mermaid 문서 범위다. 외부 디자인 canvas·생성 화면·이미지를 만들거나 실제 앱 품질을 검증하지 않았다.

### 남은 핵심 결정

Q01~21을 보존하고 Q19 사진 질문은 AI 생성 리소스·방향/anchor·사용 조건/fallback으로 개정한다. Q22~29: ID/용어·시퀀스 소속, 그룹 시간/오류/Reset, Device/자재 충돌, IDE/전환, 생성 도구/사용 조건·오차, QLT 환경/목표, UX 역할 분리, History 및 정본 반영의 중복/충돌 정책. History URL·상단 링크는 private 반영에서 확인되었고 공개 이력에 복사하지 않는다.
