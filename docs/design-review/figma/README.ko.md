## 원본 차이 주의
와이어 S71 원본에 이전 A/B/C 테마 표기가 남아 있습니다. 원본 구조·내용을 바꾸지 말라는 조건에 따라 이를 수정하거나 삭제하지 않았습니다. 표지와 해당 쪽 바깥 주석에 최신 기준은 라이트·다크 두 개라고 명시했습니다. GUI96쪽은 모두 최신 양 테마로 내보냈으며 세 번째 선택지를 추가하지 않았습니다. 이 한 곳은 원본 문서 정리 잔여 항목이지 새로운 세 테마 기준이 아닙니다.

## 내보내기 방법과 한계
- Figma 표준 `exportAsync`의 직접 PDF는 단일 프레임 반환 데이터가272,293바이트로 도구의48,000바이트 응답 한도를 초과했습니다.
- 따라서 같은 공식 연결의 표준 `SVG_STRING` 원본을 직접 내보냈습니다. 전송 압축·차이 표현은 복원 확인을 거치는 손실 없는 방식이며, 도형·좌표·색·글자 원문을 새로 만들지 않았습니다.
- 원본 SVG를 Cairo로 벡터 PDF 변환 후 프레임별로 병합했습니다. **Figma 직접 PDF는 아니며, 이미지 기반 PDF도 아닙니다.** 최종3개 PDF의 래스터 이미지 참조는0개이고 검색 가능한 글자와 벡터 도형을 유지합니다.
- 원본의 Noto Sans KR 정규·굵게를 사용하고 모든 글꼴을 PDF에 포함했습니다. 글꼴 출처는 Google Fonts의 공식 Noto Sans KR입니다. 원본 프레임의 가로·세로와 균일 확대 비율을 manifest에 기록했습니다.
- 출처·제목·정적 문서 안내는 원본 프레임 바깥 여백에 추가했습니다. 화면 내용을 덮어쓰거나 재배치하지 않았습니다. JPEG 변환·해상도 강제 축소·가독성 저하 압축은 하지 않았습니다.
- GUI는 원본 프레임의 색 변수 모드를 잠시 지정해 양 테마로 내보내고 즉시 원복했습니다.48개 활성 프레임 모두 원래 모드 상속 상태이고 페이지 모드도 불변입니다. 독립 다크 참고 사본의 기존 설정도 유지됐습니다. 기존817개 반응 출발점과 테마96개 연결 수를 확인했습니다.
- 정적 PDF에서 시제품 연결·입력·저장·실행·테마 토글은 작동하지 않습니다. 실제 플레이어 클릭과 웹 기능을 검증한 자료가 아닙니다.
